表格的边界：TD 思想没失效，存储方式失效了

原文 docs/chapter07_dqn/from-q-to-dqn.md（5.1 节）

Q-learning 的更新是“用一次新经验修正表里的一个旧数字”：Q(s,a) ← Q(s,a) + α[r + γ maxa′Q(s′,a′) − Q(s,a)]。它成立的隐含前提是状态能被枚举。原文举了一串数量级：井字棋约 2 万个局面还能建表，国际象棋约 1047，围棋约 10170；LunarLander 的 8 维状态里 6 维是连续实数，强行每维切 50 格就是 506 ≈ 1.56 × 1010 个状态；Atari 是 4 帧 84×84 灰度图，25628224 种可能。原文的判断是：失效的不是 TD 更新，而是“按状态逐行存储 Q”这种表示方式。（Q-learning 与 TD 的推导见《数学原理》07。）

函数逼近把“查表取一行”换成“函数现算一行”：网络输入状态，一次输出所有动作的 Q 值 Q(s,·;θ)，取 argmax 就是贪心动作。参数共享带来泛化——在某个状态附近学到的价值结构会迁移到相似状态。这个想法 1990 年代就有人试过，但直到 2013 年 DeepMind 的 DQN 才在 Atari 上成功，原文给的原因是：算力、训练稳定化技术、以及能大量快速交互的统一基准环境。

直接替换会撞上两个问题。样本相关：相邻帧几乎一样，按时间顺序组 batch，梯度被最近几步主导，网络围着当前局面打转。目标移动：表格里改 Q(s₁,a₂) 不会动 Q(s₂,a₂)，网络里所有输出共享 θ——一次更新在追目标的同时也挪动了目标本身。原文的数字例子：TD 目标本来是 1 + 0.99 × 8.0 = 8.92，更新一步后 Q(s₂,a₂) 从 8.0 变成 6.3，目标就跟着变了。函数逼近 + 自举 + off-policy 三者同时出现，就是 Sutton 和 Barto 说的致命三要素。

三个组件：Q 网络、经验回放、目标网络

原文 docs/chapter07_dqn/dqn-components.md；代码 code/chapter04_dqn/dqn_cartpole.py

Q 网络是“学生”：输入状态，输出每个动作的 Q 值，用 gather 挑出实际执行动作那一列。损失由四块积木拼成：TD 目标 y = r + γ(1 − d)maxa′Q(s′,a′;θ⁻)（标准答案，终止时 d = 1 把未来清零）、TD 误差 δ = y − Q(s,a;θ)、平方（惩罚大错，正负不抵消）、对 batch 取平均（外层期望用随机采样近似）。原文还解释了很多“为什么是这个值”：输出层不加激活（Q 可以是任意实数）、ReLU（Q 值无上界，sigmoid/tanh 会截断）、一次输出全部动作（选动作只需一次前向）——代价是只能用于离散动作。

经验回放把每步的 (s, a, r, s′, d) 存进一个先进先出的池子（CartPole 用 10⁴，Atari 用 10⁵–10⁶），训练时随机抽一批。好处有三：打破时间相关、每条经验可被多次使用、新旧经验混合使训练平滑。原文引用 DQN 论文的观察：不用回放时，打砖块的智能体会连续几百帧只学“球在左边”，等球回到右边，右边的打法已经忘了。池子太小不够多样，太大则保留太多当年网络很差时的过时经验。

目标网络是“阅卷老师”：Q 网络的冻结副本 θ⁻，只用来算 TD 目标，每隔 C 步把 θ 硬拷贝过去，两次拷贝之间靶子不动。更新太频繁等于没有目标网络，太稀疏则答案过时（原文常用 100–1000 步）。后来 DDPG 等算法改成每步缓慢的软更新 θ⁻ ← τθ + (1 − τ)θ⁻。训练用 ε-贪心探索、评估用纯贪心——同一个网络，两种用法。

算法卡 · DQN

Deep Q-Network（Mnih et al., 2013 / Nature 2015）

解决什么问题
状态无法枚举（连续、像素）时，表格 Q-learning 装不下；直接换成网络又训练不稳。
核心做法
Q 网络近似 Q(s,·)；经验回放随机抽样打破相关；目标网络冻结 θ⁻ 稳住 TD 目标；ε-贪心探索。
关键公式
L(θ) = 𝔼[(r + γ(1 − d) maxa′ Q(s′,a′;θ⁻) − Q(s,a;θ))²]，每 C 步 θ⁻ ← θ
何时用
离散动作、可以反复交互的环境（Atari、LunarLander、CartPole）；需要复用旧数据（off-policy）时。
代价与坑
只能离散动作；max 带来过估计；对 lr、C、ε 衰减敏感；评估曲线即使收敛后仍会波动。
相关
Double / Dueling / PER / Rainbow（本篇下文）；连续动作版 DDPG（第 5 篇）。

DQN 家族：每个改进只修一个问题

原文 docs/chapter07_dqn/dqn-family.md

原始 DQN 留下几个结构性问题，后续改进各修一处，不改变“学动作价值”这个目标。Double DQN 修过估计：TD 目标里的 max 既负责“选哪个动作”又负责“给它打分”，各动作的估计只要带噪声，max 就倾向于挑中被噪声推高的那个——因为 max 是凸函数，𝔼[max Q̂] ≥ max 𝔼[Q̂]。Double DQN 让当前网络选 a* = argmax Q(s′,·;θ)，目标网络只负责评估 Q(s′,a*;θ⁻)，代码只改两三行，许多实现默认就用它。

Dueling DQN 改网络结构：Q = V(s) + A(s,a) − meana′A(s,a′)。减去平均优势是为了让分解唯一（否则 V 加个常数、A 减同一个常数，Q 不变）。好处是在“动作差别不大、但状态好坏已定”的局面——比如飞船离地还远时——网络能先学会状态价值。优先经验回放（PER）改采样：按 pi = |δi| + ε 给“意外”的经验更高概率 P(i) = piα/Σpα；非均匀采样改变了数据分布，所以要乘重要性权重 wi = (1/(N·P(i)))β 修正偏差（常除以 batch 内最大值）。

另外三样：多步回报把后面 n 步的真实奖励直接放进目标，稀疏奖励传播更快、方差更大；分布式价值（C51）学回报的整个分布 Z(s,a) 而非期望；Noisy Net 把可学习的噪声放进参数，比 ε-贪心的“与状态无关的随机”更有结构。Rainbow 把这六样合在一起——原文的提醒是：组合更强但超参更多，调试时仍要先理解每个组件在修什么。还有一类改进针对“根本没去过关键状态”的探索问题：ICM、RND 等内在奖励（第 6 篇）。

改进改了哪里修的问题代价

算法卡 · Double DQN

van Hasselt et al., 2016

解决什么问题
max 同时“选”和“评”，噪声被挑中，Q 值系统性偏高。
核心做法
当前网络选动作，目标网络评估这个动作。
关键公式
a* = argmaxa′ Q(s′,a′;θ)，y = r + γ(1 − d) Q(s′,a*;θ⁻)
何时用
几乎总是——它是很多实现里 DQN 的默认版本。
代价与坑
只是缓解，θ 与 θ⁻ 相关时仍有残余偏差；连续动作里同样的思路演化成 TD3 的双 Q 取 min。
相关
TD3 的 Twin Q（第 5 篇）；离线 RL 的外推高估（第 6 篇）。

易混辨析：目标网络、Double DQN 与 PER

目标网络 vs 经验回放：前者稳住“标准答案”（目标移动），后者打散“样本”（时间相关）。拆掉哪个，坏掉的是不同的东西。

目标网络 vs Double DQN：目标网络让靶子慢下来，但 max 仍在同一组估计里选和评，过估计还在；Double DQN 把“选”交给 θ、“评”交给 θ⁻。

PER 的 α 与 β：α 决定“多偏心”（0 退化为均匀采样），β 决定“偏心之后修正多少”（0 等于不修正、1 完全修正）。

DQN vs Q-learning：TD 思想完全一样，变的只是 Q 的存储方式（表 → 网络）以及为此加的两个稳定化组件。

回扣开头的三个问题

先自己答，再点开

本篇公式卡

DQN：y = r + γ(1 − d) max_{a′} Q(s′,a′;θ⁻)；L = 𝔼[(y − Q(s,a;θ))²]；每 C 步 θ⁻ ← θ
软更新：θ⁻ ← τθ + (1 − τ)θ⁻（τ ≈ 0.005）
过估计：𝔼[max_a Q̂(s,a)] ≥ max_a 𝔼[Q̂(s,a)]
Double DQN：a* = argmax_{a′} Q(s′,a′;θ)，y = r + γ(1 − d) Q(s′,a*;θ⁻)
Dueling：Q(s,a) = V(s) + A(s,a) − (1/|𝒜|) Σ_{a′} A(s,a′)
PER：P(i) = p_i^α / Σ_k p_k^α，p_i = |δ_i| + ε；w_i = (1/(N·P(i)))^β
n 步目标：y = Σ_{k<n} γ^k r_{t+k} + γ^n max_a Q(s_{t+n},a;θ⁻)
1. 直接把 Q 表换成网络会冒出哪两个不稳定来源？各由谁对付？

样本相关（连续帧几乎相同，梯度被最近经历主导）→ 经验回放随机抽样；目标移动（参数共享，更新 Q(s,a) 也改了 Q(s′,·)，TD 目标随之漂移）→ 目标网络冻结一段时间再同步。三者叠加的根源是“函数逼近 + 自举 + off-policy”这一致命三要素。

2. 为什么 max 让 Q 值偏高？Double DQN 改了哪一行？

各动作估计带噪声时，max 更容易挑中被噪声推高的那个，max 是凸函数所以 𝔼[max] ≥ max 𝔼。Double DQN 只改 TD 目标：用当前网络 argmax 选 a*，用目标网络给 a* 打分。

3. PER 为什么还要乘重要性权重？Rainbow 合了哪六样？

按 |δ| 偏心采样改变了训练数据的分布，期望不再等于均匀采样下的损失，用 w = (1/(N·P))^β 修正这个偏差。Rainbow = Double DQN + Dueling + PER + 多步回报 + 分布式价值 + Noisy Net。
