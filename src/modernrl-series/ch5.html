DDPG：确定性策略 + DQN 的稳定化组件

原文 docs/chapter11_continuous_control/ddpg.md（9.1 节）

DQN 能复用旧数据，但它的 argmax 在连续动作上算不出来；PPO 能处理连续动作，但只能用新鲜数据。Silver 等人（2014）的确定性策略梯度（DPG）把两者接起来：策略直接输出一个动作 a = μθ(s)，梯度只是链式法则——∇J = 𝔼s[∇θμθ(s) · ∇aQ(s,a)|a=μ(s)]：Critic 告诉你“动作往哪边挪 Q 会变大”，再传回 Actor 的参数。不用对动作求期望，方差更低；动作是确定的，任何行为策略采的数据都能用，于是天然 off-policy。

DDPG（Lillicrap 2015）把 DPG 和 DQN 的工程组件拼在一起：Actor μθ(s)；Critic Qφ(s,a) 同时输入状态和动作、输出一个标量；两者都有目标网络，用软更新 θ′ ← τθ + (1 − τ)θ′（τ = 0.005，每步只靠近 0.5%）；回放池 10⁶。确定性策略不会探索，所以训练时给动作加高斯噪声——行为策略带噪、目标策略确定，正是 off-policy 的好处。（原论文用 OU 噪声，后来的研究发现普通高斯噪声一样好。）Actor 的损失就一行：−Q(s, μ(s))。

原文列了 DDPG 的三个毛病：Q 值过估计（比 DQN 更严重：Actor 直接朝 Critic 高估的方向冲，Critic 又被新 Actor 带得更高，形成正反馈）、超参敏感、训练易崩（Critic 学坏一点 → Actor 被带偏 → 数据变差 → Critic 更坏，一旦崩溃很难救回）。下面这个小实验看其中一个机制：Critic 的 Q 曲线上如果有一个窄窄的虚假尖峰，Actor 的梯度上升会被它吸过去。

算法卡 · DDPG

Deep Deterministic Policy Gradient（Lillicrap et al., 2015）

解决什么问题
连续动作上的 off-policy 学习：DQN 的 argmax 算不出来，PPO 又不能复用旧数据。
核心做法
确定性 Actor μ(s) + Critic Q(s,a)；回放池；Actor / Critic 各有目标网络并软更新；训练时动作加高斯噪声探索。
关键公式
y = r + γQφ′(s′, μθ′(s′))；Lactor = −Qφ(s, μθ(s))；θ′ ← τθ + (1 − τ)θ′
何时用
现在主要是教学价值；原文的实战建议是“DDPG 已不推荐”。
代价与坑
过估计正反馈、超参敏感、容易崩且救不回来。
相关
TD3（打补丁）、SAC（换目标函数）；离线版本 TD3+BC（第 6 篇）。

TD3：三个补丁，各修一个毛病

原文 docs/chapter11_continuous_control/td3-sac.md（9.2 节前半）

TD3（Fujimoto 2018）就是三个技巧。补丁一：双 Q 取 min（Twin）。训练两个独立初始化的 Critic，算目标时取较小者：y = r + γ min(Q₁′, Q₂′)(s′, a′)。一个网络偶然高估某个动作，另一个独立网络不太可能在同一处也高估；min 系统性地压低高估。原文的取舍很清楚：低估是保守的，最多学得慢；高估会形成正反馈导致发散。

补丁二：延迟策略更新（Delayed）。Critic 要拟合 Q(s,a) 这个二元函数，比 Actor 难学得多；Critic 还不准时给 Actor 的梯度就是噪声。所以 Critic 每步更新，Actor 和目标网络每 d = 2 步才更新一次，“让 Critic 先学好”。补丁三：目标策略平滑（Smoothing）。算目标时给目标动作加一点截断噪声 a′ = clip(μ′(s′) + clip(𝒩(0, 0.2), −0.5, 0.5))，等于在动作附近取平均，把 Q 函数里只是逼近噪声的窄尖峰抹平——上一节的实验里把 σ 调大就能看到这个效果。更新 Actor 时只用 Q₁ 就够了。

算法卡 · TD3

Twin Delayed DDPG（Fujimoto et al., 2018）

解决什么问题
DDPG 的过估计、Critic 不准时带偏 Actor、追逐 Q 函数的虚假尖峰。
核心做法
双 Q 取 min；Critic 每步更新、Actor 每 2 步更新；目标动作加截断噪声做局部平滑。
关键公式
a′ = clip(μ′(s′) + clip(𝒩(0, σ), −c, c))，y = r + γ mini Qφᵢ′(s′, a′)；σ = 0.2，c = 0.5，d = 2
何时用
连续控制、明确需要确定性策略（部署时不希望有随机性）。
代价与坑
仍靠外加噪声探索、要调噪声大小；min 带来轻微低估。
相关
Double DQN 的同一思想（第 2 篇）；SAC 也用双 Q；TD3+BC 是离线 RL 强基线（第 6 篇）。

SAC：把“保持随机”写进目标函数

原文 td3-sac.md（9.2 节后半）、ac-frontier.md

TD3 是在 DDPG 框架上打补丁，SAC（Haarnoja 2018）则改了目标本身：J(π) = 𝔼[Σγt(rt + α𝓗(π(·|st)))]——不只要奖励高，还要每个状态的策略熵大。原文列了三个好处：探索内建（策略本身随机，熵奖励阻止它过早塌成一个点，不用手调噪声）；鲁棒（多个动作差不多好时都保留概率，环境一变能快速切换）；Q 更平滑（与 TD3 的目标平滑异曲同工，但来自目标函数本身）。

目标变了，Bellman 方程也换成“软”版本：V(s) = 𝔼a~π[Q(s,a)] + α𝓗，Q(s,a) = 𝔼[r + γV(s′)]；离散情形下最优策略正好是 π ∝ exp(Q/α)，V = α log Σ exp(Q/α)——一个“软 max”。实现上有三个关键件：随机高斯策略配重参数化 a = μ(s) + σ(s)⊙ε（用 rsample 让梯度穿过采样）；Actor 损失 𝔼[α log π(a|s) − min(Q₁, Q₂)(s,a)]；自动调温——把 α 当可学参数，让策略熵维持在目标值附近（常取 −动作维度），熵太低就加大 α，太高就减小，用 log α 保证为正。

原文的结论很干脆：DDPG 已不推荐，TD3 是需要确定性策略时的备选，连续控制首选 SAC（off-policy 省样本、双 Q + 最大熵稳定、自动调温开箱即用）。原文也提到 SAC 在真实机器人上的成功案例，以及 NVIDIA Isaac Lab 这类工业级训练平台。

算法卡 · SAC

Soft Actor-Critic（Haarnoja et al., 2018）

解决什么问题
DDPG / TD3 靠外加噪声探索、对超参敏感；想要 off-policy 的样本效率 + 稳定性。
核心做法
最大熵目标；随机高斯策略 + 重参数化；双 Q 取 min；α 自动调节到目标熵。
关键公式
y = r + γ(min Q′(s′,ã′) − α log π(ã′|s′))；Lactor = 𝔼[α log π(a|s) − min Q(s,a)]；𝓗₀ = −|𝒜|
何时用
连续控制的首选，尤其是真实机器人这类样本昂贵的场景。
代价与坑
要用 rsample 而非 sample；log π 的 tanh 修正等实现细节多；离散动作需改写。
相关
MBPO 的底层优化器（下节）；CQL 建在 SAC 之上（第 6 篇）；最大熵思想与 RLHF 的 KL 正则同源。

基于模型：学一个环境模型来“想象”数据

原文 model-based.md（9.3 节）、search-world-models.md（9.4 节）

前面的方法都是 model-free：只看奖励调策略，不关心世界怎么运转。基于模型的 RL 先学动力学模型 P̂(s′|s,a) 和奖励模型 R̂(s,a)，然后在模型里“想象”轨迹。原文给的量级：SAC 在 MuJoCo 上通常要约 100 万步，MBPO 用 1–10 万步达到同等水平，样本效率高 10–100 倍；如果每步真实交互要 1 秒，就是 11.5 天和 1 天的差别。核心矛盾是模型偏差：在错的模型上学出的策略到真实环境里也会错，而且策略会主动钻模型的漏洞。

原文用一个递推说明误差为什么随推演长度累积：单步预测误差 ≤ ε，真实动力学的 Lipschitz 常数为 L，则 et+1 ≤ Let + ε，T 步后 eT ≤ εΣLi。L = 0.9 时误差收敛到 10ε；L = 1 时线性增长；L = 1.1 时 50 步约 1174ε——单步误差 0.01，50 步后已经超过 11。三代算法是三种应对：Dyna（Sutton 1990）每次真实交互后用模型生成 N 条假数据多做 N 次更新，简单但长推演会失真；PETS 用概率集成显式建模不确定性，再用 CEM 做模型预测控制（每步规划，部署贵）；MBPO 只从真实状态出发推演 1–5 步就重置，误差来不及累积，最后用 SAC 训练策略，部署和 model-free 一样快。

另一条旗舰路线把模型直接用于决策时的搜索：AlphaZero 用 MCTS + 策略 / 价值网络，自我对弈不靠人类棋谱；MuZero 在隐空间里学模型，连规则都不需要知道；Dreamer V3 用循环状态空间模型，在“想象”里训练 Actor-Critic，用一套超参覆盖 150 多个任务。原文把它和 LLM 连起来：RLHF / GRPO 是 model-free；过程奖励模型 + 推理时搜索就是 AlphaZero“网络引导搜索、搜索结果强于网络”的翻版（第 10 篇）；代码世界模型则是在 LLM 里重建 MuZero / Dreamer 的思路。

算法卡 · MBPO

Model-Based Policy Optimization（Janner et al., 2019）

解决什么问题
真实交互昂贵；但长推演的模型误差会累积到完全失真。
核心做法
用真实数据训练模型集成 → 从回放池里的真实状态出发推演 k（1–5）步 → 真假数据混合，用 SAC 更新；k 随模型变准逐步加大。
关键公式
误差界 ek ≤ εΣi<kLi；性能差距 ~ O(εm/(1 − γ)²)，短推演相当于缩短有效视野
何时用
机器人、工业控制等每一步都贵的场景；部署时不想每步规划。
代价与坑
模型质量决定一切，超参（模型容量、训练频率、k）更敏感；渐进性能可能被模型误差卡住天花板。
相关
Dyna、PETS；Dreamer（想象中训练）；第 6 篇的离线 RL 同样在对付“没见过的区域”。

分一分：这个场景先考虑哪一类

易混辨析：model-based 与 model-free

“模型”指什么：环境的转移与奖励 P̂(s′|s,a)、R̂(s,a)，不是“神经网络模型”。DQN 有网络，但它是 model-free。

样本效率 vs 渐进性能：model-based 省真实样本；样本无限时 model-free 通常最终更强，因为没有模型偏差。

数据增强路线 vs 搜索路线：Dyna / MBPO 用模型“造数据”，最后仍以 model-free 方式训练策略；AlphaZero / MuZero / PETS 在决策时用模型搜索或规划。

确定性策略 vs 随机策略的 off-policy：DDPG / TD3 靠确定性 μ(s) + 外加噪声；SAC 是随机策略，靠重参数化和熵项，同样 off-policy。

1. DDPG 怎样在连续动作上做 off-policy？三个缺陷各被 TD3 哪个补丁修复？

确定性 Actor 直接输出动作，梯度是 ∇μ·∇ₐQ 的链式法则；配回放池、软更新目标网络、训练时加噪声探索。过估计 → 双 Q 取 min；Critic 不准带偏 Actor → 延迟策略更新（d = 2）；追逐 Q 的虚假尖峰 → 目标策略平滑（目标动作加截断噪声）。

2. 最大熵目标多了什么？α 起什么作用、怎样自动调？

每一步额外奖励 α·策略熵：探索内建、多个好动作都保留概率、Q 更平滑。α 是温度：大则更随机，小则退化为普通 RL；π ∝ exp(Q/α)。自动调温把 log α 当参数，让熵贴近目标值 −|𝒜|：熵低于目标时增大 α，高于目标时减小。

3. 基于模型为什么省样本？MBPO 为什么只推演约 5 步？

模型学好后在模型里“想象”采样几乎零成本，原文给的样本效率提升是 10–100 倍。但模型误差按 e_T ≤ εΣL^i 累积，L ≥ 1 时长推演会失真。MBPO 从真实状态出发只推演 1–5 步就重置，吃掉“误差还很小的那一段”，再用 SAC 训练。
