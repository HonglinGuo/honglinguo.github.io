这份教程

原文 README、LEARNING-ROADMAP

Claude How To 是 luongnv89 发起的开源教程（MIT 协议），口号是“用一个周末掌握 Claude Code”。它认为大多数人只用到了 Claude Code 很小一部分能力，原因是官方文档按功能讲、不讲组合，没有学习路径，示例太基础。所以它把每个功能做成一个模块，配原理图、可复制的模板（命令、CLAUDE.md、hook 脚本、MCP 配置、子代理定义、完整插件）和一条约 11–13 小时的学习路线。

两点说明。版本：笔记依据 2026 年 10 月 20 日的仓库版本（commit 188f468），原文标注对应 Claude Code v2.1.302；Claude Code 迭代极快，带版本号的细节以原文和官方文档为准。语言：中文版（zh/）是英文原版的缩写译本，很多模块只有英文的五分之一，笔记主要依据英文原版，每节标出对应的原文目录。

文件放哪

各功能的位置与同名优先级

七件套各自有个人、项目、本地、组织几层位置，同名时谁生效的规则还不一样（Skills 是个人盖过项目，Subagents 是项目盖过个人）。这张表收在一起。“提交”指放进项目仓库、随 git 共享。
