状态值的 TD 学习

原书 7.1 节 · 第 126–133 页

给定策略 π，手里有按 π 产生的经验 (s0, r1, s1, …, st, rt+1, st+1, …)。TD 算法这样估计状态值：

vt+1(st) = vt(st) − αt(st) [ vt(st) − (rt+1 + γvt(st+1)) ]，其余状态不变原书式 (7.1)(7.2)

为什么这样设计？把状态值的定义改写成 vπ(s) = 𝔼[Rt+1 + γvπ(St+1)|St = s]——这是贝尔曼方程的另一种写法，也叫贝尔曼期望方程。对它用 RM 算法：令 g(v(st)) = v(st) − 𝔼[R + γvπ(S′)|st]，观测样本 (rt+1, st+1) 得到带噪声的 g̃，就推出了上式（原书框 7.1）。唯一的差别是 RM 推导里用的是真值 vπ(st+1)，实际只能换成估计 vt(st+1)；定理 7.1 证明换了以后仍然收敛（用第 6 章的定理 6.3），条件是每个状态的步长满足 Σα = ∞、Σα² < ∞——这要求每个状态都被访问无穷多次。

两个名词。TD 目标 v̄t = rt+1 + γvt(st+1)：算法把 v(st) 往它推，因为 |vt+1(st) − v̄t| = |1 − α||vt(st) − v̄t| < |vt(st) − v̄t|。TD 误差（原书定义）δt = vt(st) − (rt+1 + γvt(st+1))：一方面是两个时刻之间的差异（所以叫“时序差分”）；更重要的是，估计准确时它的期望为 0，所以它反映的是估计与真值的差距——可以理解为新样本带来的新息（innovation），和卡尔曼滤波里的概念相通。

TD 与 MC 的对比（原书表 7.1）见下表。核心差别：TD 增量、能处理持续任务、自举（依赖初始猜测）、估计方差小（只涉及 Rt+1, St+1, At+1 几个随机变量）；MC 非增量、只能处理回合任务、不自举、方差大（回报里有一长串随机变量，长度 L 的回合在软策略下有 |𝒜|L 种可能）。

Sarsa：估计动作值，再改进策略

原书 7.2 节 · 第 133–138 页

状态值 TD 只能评估策略；要找最优策略，得估计动作值再做策略改进。把 TD 里的状态值换成动作值就是 Sarsa：

qt+1(st, at) = qt(st, at) − αt [ qt(st, at) − (rt+1 + γqt(st+1, at+1)) ]原书式 (7.12)

每次更新要用 (st, at, rt+1, st+1, at+1) 五个量，名字就是 state-action-reward-state-action 的缩写。它在解动作值形式的贝尔曼方程 qπ(s, a) = 𝔼[R + γqπ(S′, A′)|s, a]，定理 7.2 保证它收敛到 qπ。

与策略改进结合（算法 7.1）：每走一步，先更新被访问的那一个 q(st, at)，然后立刻把 st 的策略改成对 q 的 ε-贪心。策略根本没评估准就改了——这正是广义策略迭代。策略必须是 ε-贪心，因为它还要用来产生下一个样本，得有探索性。Expected Sarsa（框 7.4）把目标里的 q(st+1, at+1) 换成按策略的期望 Σaπ(a|st+1)q(st+1, a) = v(st+1)：计算稍多，但少了 At+1 这个随机变量，方差更小。

原书图 7.2 的任务和前几章不同：只求从左上角到目标的一条最优路径，不求所有状态的最优策略（就像只关心从家到单位的路）。回合从左上角开始、到目标结束；rtarget = 0，rforbidden = rboundary = −10，rother = −1，α = 0.1，ε = 0.1，q0 = 0。随着训练，每回合的总奖励上升、长度下降，偶尔会突然变差——那是 ε-贪心在走随机动作，可以用逐渐衰减的 ε 解决。因为不必探索所有状态，路径外的状态策略未必最优，路径本身也可能只是局部最优。

训练 500 个回合，看学到的路径和两条学习曲线；也可以换成 Expected Sarsa 或下面要讲的 Q-learning 比较。

算法 7.1　用 Sarsa 学最优策略on-policy

  1. 初始化 α > 0、ε ∈ (0, 1)、q0(s, a)，以及由 q0 导出的 ε-贪心策略 π0。对每个回合：在 s0 按 π0 选 a0；当 st 不是目标：
    1. 与环境交互得 rt+1、st+1；按 πt(st+1) 选 at+1
    2. 更新 q(st, at)：q ← q − α[q − (r + γ q(s′, a′))]
    3. 更新 st 的策略为对 q(st, ·) 的 ε-贪心；s ← s′，a ← a′

n 步 Sarsa：Sarsa 与 MC 之间

原书 7.3 节 · 第 138–140 页

回报 Gt 可以有多种分解：Gt = Rt+1 + γqπ(St+1, At+1)（一步）、= Rt+1 + γRt+2 + γ2qπ(St+2, At+2)（两步）……、= Rt+1 + γRt+2 + γ2Rt+3 + …（展开到底）。它们是同一个随机变量，只是写法不同。代入 qπ(s, a) = 𝔼[Gt|s, a]，用随机近似求解，就得到不同算法：n = 1 是 Sarsa，n = ∞（并取 α = 1）是 MC，一般的 n 就是 n 步 Sarsa：

qt+1(st, at) = qt(st, at) − α[ qt(st, at) − (rt+1 + γrt+2 + … + γnqt(st+n, at+n)) ]原书式 (7.17)

实现上要等到 t + n 时刻才凑齐所需的样本，所以 q(st, at) 的更新推迟到 t + n。性能也介于两者之间：n 大接近 MC，方差大、偏差小；n 小接近 Sarsa，偏差大（依赖不准的初始估计）、方差小。它同样只是策略评估，要配合策略改进才能学最优策略。

拖动 n 看目标的组成；下面的小实验用 n 步 TD 评估均匀策略（与 n 步 Sarsa 同理），比较不同 n 和 α 下的误差（示意）。

Q-learning：直接学最优动作值

原书 7.4 节 · 第 140–145 页

Sarsa 只能估计给定策略的动作值，必须配合策略改进；Q-learning 直接估计最优动作值：

qt+1(st, at) = qt(st, at) − αt [ qt(st, at) − (rt+1 + γ maxa qt(st+1, a)) ]原书式 (7.18)

与 Sarsa 只差 TD 目标：maxaq(st+1, a) 代替 q(st+1, at+1)，于是每次只需要 (rt+1, st+1)，不需要 at+1。数学上它在解动作值形式的贝尔曼最优方程 q(s, a) = 𝔼[Rt+1 + γ maxaq(St+1, a)|s, a]（两边取 max 就回到第 3 章的 BOE）。

这引出一对重要概念。任何强化学习任务里都有两个策略：行为策略（产生经验样本）和目标策略（不断更新、最终收敛到最优）。两者相同叫 on-policy，不同叫 off-policy。off-policy 的好处是能用别的策略（甚至人类操作）产生的数据学习，尤其可以用探索性很强的行为策略。判断方法：看算法解的是什么方程、需要什么样本。Sarsa 是 on-policy：它评估 π 需要 π 产生的 at+1，被评估、被改进的就是产生样本的那个策略。Q-learning 是 off-policy：根本原因是它解的是贝尔曼最优方程；样本 (st, at, rt+1, st+1) 里只有 at 来自行为策略，r 和 s′ 由环境决定，所以 at 可以由任何策略产生。MC 是 on-policy，理由同 Sarsa。

原书图 7.4、7.5：用均匀随机的行为策略产生一条 10 万步的回合，用 Q-learning（off-policy 版，目标策略取贪心、不必探索）学所有状态的最优策略，状态值误差收敛到 0；学到的策略可能和基准答案不同，但同样最优。初值离真值越远收敛越慢；行为策略探索性越弱（ε 从 1 降到 0.5、0.1），学得越慢。

算法 7.3　Q-learning（off-policy 版）行为策略 πb 可以是任何策略

  1. 初值 q0(s, a)，行为策略 πb，步长 α。对 πb 产生的每个回合的每一步 t：
    1. 更新 q(st, at)：q ← q − α[q − (r + γ max_a q(s′, a))]
    2. 目标策略 πT(·|st) 设为对 q(st, ·) 的贪心（不需要探索）

易混辨析：on-policy vs off-policy

on-policy：行为策略 = 目标策略。Sarsa、n 步 Sarsa、MC：它们在评估“产生样本的那个策略”。off-policy：两者可以不同。Q-learning：它解的是贝尔曼最优方程，估计 q*(st, at) 用到的 r、s′ 只由环境决定，at 由谁产生都行。

Q-learning 的两种实现：on-policy 版用同一个 ε-贪心策略既采样又改进；off-policy 版用独立的行为策略采样，目标策略取贪心（不用来采样，不需要探索）。第 10 章用重要性采样把 on-policy 算法也变成 off-policy。

易混辨析：on/off-policy vs online/offline

online：边与环境交互边更新；offline：用事先收集好的数据更新，不再交互。on-policy 算法可以 online，但不能用别的策略事先收集的数据；off-policy 算法 online、offline 都可以。上面的实验就是 off-policy + offline。

易混辨析：Sarsa vs Q-learning

目标：r + γq(s′, a′)（a′ 由当前策略实际选出）vs r + γ maxaq(s′, a)。解的方程：贝尔曼方程（评估当前策略）vs 贝尔曼最优方程。所需样本：(s, a, r, s′, a′) vs (s, a, r, s′)。

统一视角

原书 7.5–7.7 节 · 第 145–150 页

本章所有动作值 TD 算法都能写成同一个式子：qt+1(st, at) = qt(st, at) − αt[qt(st, at) − q̄t]，差别只在 TD 目标 q̄t。MC 也是特例：取 α = 1，就是 qt+1 = q̄t。从随机近似的角度，它们都在求解 q(s, a) = 𝔼[q̄t|s, a]——除 Q-learning 解贝尔曼最优方程外，其余都解某个策略的贝尔曼方程。

原书 Q&A 里还有两个实用问题。一是为什么实践中步长常取小常数，而不是满足 Σα² < ∞ 的衰减序列：学最优策略时被评估的策略一直在变（非平稳），衰减的步长会变得太小，来不及跟上；常数步长的代价是估计最终会小幅波动，步长足够小时可以忽略。二是要不要为所有状态学最优策略：只要一条路径（如图 7.2）对数据要求低，但因为没探索全部状态，得到的路径未必全局最优。

分一分

易混辨析：TD 误差的符号

原书第 7 章把 TD 误差定义为 δt = v(st) − (rt+1 + γv(st+1))（估计减目标），更新写成 v ← v − αδ。第 8、10 章和多数文献写成 δt = rt+1 + γv(st+1) − v(st)（目标减估计），更新写成 v ← v + αδ。两种写法是同一个更新，只是符号约定不同，读公式时要先看清定义。

易混辨析：MC vs TD；自举

MC：用完整回报，不自举，无偏、方差大、要等回合结束。TD：用一步奖励 + 下一状态的当前估计，自举，依赖初值（有偏）、方差小、每步都能更新。n 步 TD 在两者之间连续过渡。

回扣三问

  1. TD 解什么方程？TD 目标和误差是什么？比 MC 好在哪？
    先自己答，再点开

    TD 是用 RM 算法求解贝尔曼期望方程 vπ(s) = 𝔼[R + γvπ(S′)|s] 的随机近似算法。TD 目标 r + γv(s′) 是 v(s) 被推向的值；TD 误差是估计与目标之差，估计准确时期望为 0，代表新样本带来的新息。TD 增量、能处理持续任务、方差小，但自举、依赖初值。

  2. Sarsa、n 步 Sarsa、Q-learning 区别？为何 Q-learning 是 off-policy？
    先自己答，再点开

    只差 TD 目标：一步实际动作、n 步、对下一状态取 max。Q-learning 解的是贝尔曼最优方程，估计 q*(s, a) 只依赖环境给出的 r、s′，与产生 a 的行为策略无关，所以行为策略可以任意；其余算法评估的就是产生样本的策略，是 on-policy。

  3. on/off-policy 与 online/offline 的区别？
    先自己答，再点开
