策略：从表格到函数

原书 9.1 节 · 第 192–193 页

把策略写成 π(a|s, θ)，θ 是参数（比如神经网络的权重）。和表格相比有三处不同。最优怎么定义：表格时，最优策略在每个状态上都让状态值最大；函数时，改为让某个标量指标最大。怎么更新：不能直接改表格里的数，只能改 θ。怎么取概率：要把 (s, a) 代进函数计算；也可以设计成输入 s、一次输出所有动作的概率。

为了后面能取对数，必须保证每个动作的概率都大于 0。常用 softmax：π(a|s, θ) = eh(s, a, θ) / Σa′eh(s, a′, θ)，h 是对动作 a 的“偏好”，用神经网络实现时输出层就是 softmax 层。这样的策略天然是随机的、有探索性：它不直接告诉你选哪个动作，而是给出一个分布去采样。

基本思路就一行：θt+1 = θt + α∇θJ(θt)。剩下三个问题：用什么指标（9.2）、梯度怎么算（9.3）、怎么用样本估计梯度（9.4）。

拖动一个状态里 5 个动作的偏好 h，看 softmax 给出的概率。

softmax 策略：偏好 h(s, a) → 概率 π(a|s)

定义最优策略的两类指标

原书 9.2 节 · 第 193–198 页

指标一：平均状态值 v̄π = Σsd(s)vπ(s) = 𝔼S∼d[vπ(S)]，d 是状态上的权重分布。d 怎么选？一种是与策略无关，记作 d0、v̄π0：可以均匀（所有状态同等重要），也可以只关心某个起点 s0（d0(s0) = 1）。另一种是依赖策略，取平稳分布 dπ：常去的状态权重大。文献里常见的 J(θ) = 𝔼[ΣtγtRt+1] 其实就是 v̄π（用全期望公式展开即得）；它还能写成内积 dTvπ。

指标二：平均（单步）奖励 r̄π = Σsdπ(s)rπ(s)，rπ(s) = Σaπ(a|s, θ)r(s, a) 是该状态下即时奖励的期望。文献里常见的 limn→∞(1/n)𝔼[Σt=0n−1Rt+1] 就等于它（框 9.1：用 Cesàro 平均和平稳分布的定义证明，而且与起点无关）。

两者看起来一个看长期、一个只看一步，其实在折扣情形下是等价的。引理 9.1：取 d = dπ 时，r̄π = (1 − γ)v̄π。证明只有一行：对贝尔曼方程 vπ = rπ + γPπvπ 两边左乘 dπT，利用 dπTPπ = dπT 得 v̄ = r̄ + γv̄。所以两个指标可以同时最大化。

用一族 softmax 策略 πτ(a|s) ∝ eq*(s, a)/τ 在 5×5 网格上验证：τ 小接近最优，τ 大接近均匀随机。下面每个数都是按模型精确算的，最后一项是跑一条 20 万步轨迹的平均奖励。

策略梯度定理

原书 9.3 节 · 第 198–210 页

这是本章最重要的理论结果。定理 9.1：

∇θJ(θ) = Σsη(s) Σa∇θπ(a|s, θ) qπ(s, a) = 𝔼S∼η, A∼π(S, θ)[∇θln π(A|S, θ) qπ(S, A)]原书式 (9.8)(9.9)

它其实是三个定理的总结：J 可以是 v̄π0、v̄π 或 r̄π，η 是相应的状态分布，等号有的严格、有的近似（见下表）。原书说，对多数读者知道这个结论就够了，推导可以选读。推导的骨架是引理 9.2：∇vπ(s) = Σs′Prπ(s′|s)Σa∇π(a|s′, θ)qπ(s′, a)，其中 Prπ(s′|s) = [(I − γPπ)−1]ss′ = Σkγk[Pπk]ss′ 是“从 s 出发、任意步数到达 s′ 的折扣总概率”。

为什么出现 ln？为了把梯度写成期望，这样才能用样本（随机梯度）去近似。关键是对数导数技巧：∇θln π = ∇θπ / π，所以 Σa∇π(a|s)q(s, a) = Σaπ(a|s)∇ln π(a|s)q(s, a) = 𝔼A∼π[∇ln π(A|s)q(s, A)]。这也是 π 必须处处为正的原因。

蒙特卡罗策略梯度：REINFORCE

原书 9.4 节 · 第 210–213 页

梯度上升 θt+1 = θt + α𝔼[∇ln π(A|S, θt)qπ(S, A)] 里的期望未知，换成随机梯度：

θt+1 = θt + α∇θln π(at|st, θt) qt(st, at)原书式 (9.32)

qt 是 qπ(st, at) 的估计。如果用蒙特卡罗（从 t 开始的折扣回报）来估计，就是 REINFORCE（也叫蒙特卡罗策略梯度），最早、最简单的策略梯度算法之一，很多算法都由它扩展而来。

原书建议看它的等价形式：θt+1 = θt + αβt∇θπ(at|st, θt)，βt = qt(st, at)/π(at|st, θt)。这是对 π(at|st) 本身的梯度上升，一阶泰勒展开得 πnew ≈ πold + αβt‖∇π‖2：βt ≥ 0 时这个动作的概率增大，βt < 0 时减小，|β| 越大改得越多。而 βt 同时体现了两件事：与 qt 成正比——值大的动作被加强，这是利用；qt > 0 时与 π 成反比——本来很少选的动作一旦被选中且回报不错，会被大幅加强，这是探索。

样本该怎么采？S 应服从 η（dπ 或 ρπ，都是 π 下的长期行为），A 应服从 π(·|S, θ)：动作必须由当前策略产生，所以策略梯度是 on-policy。理想采样方式效率低，实际中并不严格遵守：算法 9.1 先按 π(θ) 生成一整个回合，再用回合中的每个样本更新 θ。

先在一个状态、三个动作上体会 β 的作用；再在网格里训练一个表格 softmax 策略。

算法 9.1　REINFORCE（蒙特卡罗策略梯度）

  1. 初始参数 θ，γ ∈ (0, 1)，α > 0。对每个回合：按 π(θ) 生成 {s0, a0, r1, …, sT−1, aT−1, rT}；对 t = 0, 1, …, T − 1：
    1. 值更新：q_t(s_t, a_t) = Σ_{k=t+1}^{T} γ^{k−t−1} r_k
    2. 策略更新：θ ← θ + α ∇_θ ln π(a_t|s_t, θ) q_t(s_t, a_t)

β = q/π：一次更新会怎样改变概率（单状态三动作，α = 0.5，示意）

易混辨析：基于值 vs 基于策略

基于值（第 4–8 章）：先估计值，再从值里取贪心 / ε-贪心得到策略；策略是“派生”的。基于策略（第 9–10 章）：策略本身是带参数的函数，直接对标量指标做梯度上升；天然随机、天然能处理大的或连续的动作空间。

但仍需要值：策略梯度里有 qπ(s, a)，必须另外估计——用 MC 就是 REINFORCE，用 TD 就是第 10 章的 Actor-Critic。

回扣三问

  1. 函数表示下最优怎么定义？两个指标什么关系？
    先自己答，再点开

    改为最大化一个标量指标：平均状态值 v̄（按 d 加权的状态值）或平均奖励 r̄（平稳分布下的平均单步奖励）。折扣情形下 r̄π = (1 − γ)v̄π，两者可以同时最大化。

  2. 策略梯度定理说了什么？为什么有 ln？
    先自己答，再点开

    各种指标的梯度都具有 Σsη(s)Σa∇π q 的形式，可写成期望 𝔼[∇ln π(A|S)q(S, A)]，不需要对状态分布求导。ln 来自对数导数技巧 ∇π = π∇ln π，作用是把梯度写成期望，从而能用样本近似。

  3. REINFORCE 在做什么？怎样兼顾探索与利用？为何 on-policy？
    先自己答，再点开

    用 MC 回报估计 q，沿 ∇ln π 方向更新 θ；等价于对 π(at|st) 做系数为 β = q/π 的梯度上升。β 与 q 成正比（利用），q > 0 时与 π 成反比（探索）。真实梯度要求 A ∼ π(θ)，动作必须由当前策略产生，所以是 on-policy。
