本篇要回答的 3 个问题

  1. 状态值和回报是什么关系？“自举”为什么不是死循环？
  2. 贝尔曼方程长什么样、每一项是什么意思？怎么从它解出一个策略的全部状态值？

回报为什么重要，又该怎么算

原书 2.1–2.2 节 · 第 16–19 页

原书图 2.2 是一个 2×2 网格：s2 是禁区，s4 是目标。三个策略只在 s1 不同——向下绕开禁区、向右进禁区、各 0.5。从 s1 出发算折扣回报：γ/(1 − γ)、−1 + γ/(1 − γ)、−0.5 + γ/(1 − γ)。对任何 γ 都有“策略 1 > 策略 3 > 策略 2”，数学和直觉一致。注意第三个其实不是一条轨迹的回报，而是两条轨迹回报的平均——它已经是下一节要定义的“状态值”了。

回报怎么算有两种办法。一是按定义，沿轨迹把折扣奖励加起来。二是自举（bootstrapping）：看原书图 2.3 的四个状态绕圈，从 si 出发的回报 vi 满足 v1 = r1 + γv2、v2 = r2 + γv3……每个值都依赖另一个值，最后 v4 又依赖 v1。乍看是死循环，写成矩阵就清楚了：

v = r + γPv　⇒　v = (I − γP)−1 rP 是“下一状态是谁”的 0/1 矩阵

这就是最简单的贝尔曼方程：从一个状态出发的回报，取决于从其他状态出发的回报。“自举”指用待求的量来表达它自己——不是循环论证，而是一组联立方程。

状态值：回报的期望

原书 2.3 节 · 第 19–20 页

先把记号定下来。时刻 t 智能体在状态 St，按策略 π 采取动作 At，转到 St+1 并得到即时奖励 Rt+1。它们都是随机变量。从 t 开始的折扣回报 Gt = Rt+1 + γRt+2 + γ2Rt+3 + … 也是随机变量。对它取条件期望，就是状态值（状态值函数）：

vπ(s) ≐ 𝔼[Gt | St = s]

三点说明：它依赖 s（从哪儿出发）；依赖 π（换个策略，轨迹分布就变了）；不依赖 t（策略给定后它就是一个确定的数）。如果策略和模型都是确定性的，从一个状态出发只有一条轨迹，状态值就等于那条轨迹的回报；只要有随机性，状态值就是许多回报的平均。

状态值是全书的核心概念：状态值越大的策略越好。第 3 章会正式用它定义“最优策略”。接下来的问题是：怎么算？

用一个随机策略看看“回报是随机的、状态值是它的均值”：从 s1 反复跑，观察回报的平均怎么逼近 vπ(s1)。

贝尔曼方程

原书 2.4–2.5 节 · 第 20–25 页

推导只用两个事实：回报可以拆成“眼前一步 + 折扣后的下一个回报”，Gt = Rt+1 + γGt+1；以及马尔可夫性。于是 vπ(s) = 𝔼[Rt+1|St = s] + γ𝔼[Gt+1|St = s]，两项分别是即时奖励的均值和未来奖励的均值。第二项里，马尔可夫性让 𝔼[Gt+1|St = s, St+1 = s′] = 𝔼[Gt+1|St+1 = s′] = vπ(s′)。合起来就是贝尔曼方程：

vπ(s) = Σa π(a|s) [ Σr p(r|s, a) r + γ Σs′ p(s′|s, a) vπ(s′) ]，对所有 s ∈ 𝒮原书式 (2.7)

读法：vπ(s) 和 vπ(s′) 是未知数；π(a|s) 是给定的策略；p(r|s, a)、p(s′|s, a) 是模型。关键在于它不是一个方程，而是每个状态各一个、联立的一组线性方程。从中解出状态值，就叫策略评估。文献里还有两种等价写法：Σa π(a|s) Σs′,r p(s′, r|s, a)[r + γvπ(s′)]（Sutton 的写法），以及奖励只依赖 s′ 时的 Σa π(a|s) Σs′ p(s′|s, a)[r(s′) + γvπ(s′)]。

对具体例子，这个吓人的式子会变得很简单。原书图 2.4（s1 向下）的四个方程是 v(s1) = 0 + γv(s3)，v(s2) = 1 + γv(s4)，v(s3) = 1 + γv(s4)，v(s4) = 1 + γv(s4)。

点“下一步”逐行展开推导；然后自己手算两个例子再对答案。

推导贝尔曼方程，一步一步

  1. 回报的递推：
    Gt = Rt+1 + γ(Rt+2 + γRt+3 + …) = Rt+1 + γGt+1
  2. 取条件期望、拆成两项：
    vπ(s) = 𝔼[Rt+1|St = s] + γ𝔼[Gt+1|St = s]
  3. 即时奖励的均值（全期望公式）：
    𝔼[Rt+1|St = s] = Σa π(a|s) Σr p(r|s, a) r
  4. 未来奖励的均值，第二个等号用到马尔可夫性：
    𝔼[Gt+1|St = s] = Σs′ 𝔼[Gt+1|St+1 = s′] p(s′|s) = Σs′ vπ(s′) Σa p(s′|s, a) π(a|s)
  5. 合并，就是对每个状态成立的贝尔曼方程：
    vπ(s) = Σa π(a|s)[Σr p(r|s, a)r + γΣs′ p(s′|s, a) vπ(s′)]

矩阵形式与两种解法

原书 2.6–2.7 节 · 第 25–30 页

把每个状态的方程叠起来。记 rπ(s) = Σa π(a|s) Σr p(r|s, a) r（按策略平均的即时奖励），pπ(s′|s) = Σa π(a|s) p(s′|s, a)（按策略平均的转移概率），就得到

vπ = rπ + γPπvπ原书式 (2.10)，[Pπ]ij = pπ(sj|si)

Pπ 是非负矩阵，每行和为 1（随机矩阵，Pπ𝟙 = 𝟙）。两种解法：闭式解 vπ = (I − γPπ)−1rπ。I − γPπ 一定可逆（Gershgorin 圆盘：每个圆盘的半径 γΣj≠ipij 小于圆心 1 − γpii，圆盘不含原点），而且 (I − γPπ)−1 = I + γPπ + γ2Pπ2 + … ≥ I，奖励越大值越大。闭式解适合理论分析，实际要求逆不划算。

迭代解：vk+1 = rπ + γPπvk，从任意 v0 出发都收敛到 vπ。证明只有一行：误差 δk = vk − vπ 满足 δk+1 = γPπδk，于是 δk = γkPπkδ0，而 Pπk 的元素都不超过 1、γk → 0。这个迭代第 4 章会原封不动地用在策略迭代里。

从状态值到动作值

原书 2.8 节 · 第 30–33 页

动作值是在状态 s 先采取动作 a、之后再按 π 走所得回报的期望：qπ(s, a) ≐ 𝔼[Gt|St = s, At = a]。它依赖的是“状态—动作对”，严格说该叫状态—动作值。它和状态值的关系是两条互逆的式子：

vπ(s) = Σa π(a|s) qπ(s, a)(2.13)：状态值是动作值按策略的平均
qπ(s, a) = Σr p(r|s, a) r + γ Σs′ p(s′|s, a) vπ(s′)(2.14)：动作值由下一状态的状态值决定

原书专门点名一个初学者常犯的错误：策略不选的动作，它的动作值不是 0，也不是“不用算”。在 s1 向上（策略从不这么做）的动作值是“撞墙得 −1，然后回到 s1 继续按 π 走”：qπ(s1, a1) = −1 + γvπ(s1)。为什么要关心？因为给定的策略可能不好，恰恰错过了最好的动作；要找最优策略，就得知道所有动作的值。

把 (2.13) 代入 (2.14)，得到用动作值表示的贝尔曼方程 qπ(s, a) = Σr p(r|s, a) r + γΣs′ p(s′|s, a) Σa′ π(a′|s′) qπ(s′, a′)，矩阵形式 qπ = r̃ + γPΠqπ。其中 r̃、P 只由模型决定，策略全部装在分块对角阵 Π 里。第 5、7 章的无模型算法直接估计的就是动作值。

易混辨析：状态值 vs 动作值

状态值 vπ(s)：从 s 出发、全程按 π 走的期望回报。动作值 qπ(s, a)：在 s 先做 a（不管 π 选不选它），之后按 π 走的期望回报。

换算：v 是 q 按 π 的加权平均；q 是“一步奖励 + γ × 下一状态的 v”。前者不需要模型，后者需要 p(s′|s, a)——所以无模型算法直接估计 q（第 5 章）。

易混辨析：回报 vs 状态值；自举

回报 Gt：一条轨迹上的随机量。状态值：它的期望，是确定的数。确定性策略和模型下二者相等。

自举：用待求的值（其他状态的值）来表示一个值。贝尔曼方程本身就是自举的；第 7 章的 TD 也是，而第 5 章的蒙特卡罗不是。

回扣三问

  1. 状态值和回报是什么关系？自举为什么不是死循环？
    先自己答，再点开

    状态值是从该状态出发所得回报的期望；确定性时两者相等。自举的方程组是联立的线性方程 v = r + γPv，可以整体求解（闭式或迭代），不是一个未知数等于另一个未知数的死循环。

  2. 贝尔曼方程每一项是什么？怎么解？
    先自己答，再点开

    vπ(s) = 即时奖励均值 + γ × 下一状态值的均值；π 给定，p 是模型。叠成矩阵 v = rπ + γPπv，闭式解 (I − γPπ)−1rπ，或迭代 vk+1 = rπ + γPπvk，这就是策略评估。

  3. 动作值和状态值怎么换算？没被选的动作有值吗？
    先自己答，再点开

    v = Σa π q；q = r + γΣ p(s′|s, a) v(s′)。没被选的动作照样有动作值（做一次这个动作、之后再按 π 走），找更好的策略恰恰要靠它们。
