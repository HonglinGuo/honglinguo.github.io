问题驱动的迭代

原书第 2 章导言，图 2.1

原书第二章开头的一句话是整章的钥匙：每一个新范式的出现，都是为了解决上一代范式的核心痛点；新方案带来能力飞跃的同时，也引入了当时难以克服的新局限，于是又催生下一代。按这条线记历史，比背年代和人名有用得多，而且能解释今天的技术选型：为什么现代智能体要把规则（符号）和模型（神经网络）结合，为什么多智能体的想法早在 1986 年就有了。

符号主义：智能就是符号运算

原书 2.1 节

符号主义的理论根基是纽厄尔和西蒙 1976 年提出的物理符号系统假说（PSSH），两个论断：充分性，任何物理符号系统都有产生通用智能的充分手段；必要性，任何展现通用智能的系统本质上都是物理符号系统。一句话：智能的本质就是符号的计算与处理。它把心智这个哲学问题变成了一个工程问题，只要找到正确的知识表示和推理算法就行。

最成功的产物是专家系统，核心是知识与推理分离：知识库存放领域专家的 IF-THEN 产生式规则，推理机是通用程序，负责在规则上推导。推理机有两种工作方式：正向链从已知事实出发，不断匹配规则的 IF 部分、把结论加入事实库，是数据驱动；反向链从要证明的目标出发，找能推出它的规则，把规则的条件当成新的子目标递归下去，缺什么事实就问用户，是目标驱动。斯坦福的 MYCIN（约 600 条规则，诊断细菌性血液感染）就用反向链，还引入了 −1 到 1 的置信因子处理不确定性，表现超过非专业医生。另一个代表 SHRDLU 在积木世界里把语言理解、规划、记忆整合成一个系统，能回答“你为什么拿起红积木？”“因为你让我拿的。”

走出微观世界后，符号主义碰上两类根本难题：知识获取瓶颈（专家知识难以访谈、提炼成规则，很多是内隐的；Cyc 项目做了几十年常识库，成果有限）和常识问题；以及框架问题（动作之后哪些东西没变，逐条声明不可行）和脆弱性（规则外的一点变化就失灵）。

迷你专家系统：知识库 + 推理机

    易混辨析：正向链 vs 反向链

    正向链是数据驱动：手上有什么事实就触发什么规则，会推出很多与当前问题无关的结论，适合监控、告警关联这类“有新数据就看看能推出什么”的场景。反向链是目标驱动：只沿着能证明目标的规则往回找，缺事实才去问，适合诊断这类“有明确假设要验证”的场景，所以 MYCIN 选它。

    和 ELIZA 聊聊

    原书 2.2 节

    ELIZA 是魏泽鲍姆 1966 年在 MIT 写的聊天程序，最出名的 DOCTOR 脚本模仿罗杰斯学派的心理治疗师：从不正面回答，而是把你的话改写成一个开放式提问。机制只有四步：关键词识别与排序（多个关键词时取优先级最高的规则）、分解（用带通配符的模式捕获句子剩余部分）、代词转换（I → you，my → your）、重组（从该规则的回复模板里随机选一个，把捕获内容填进去）。

    魏泽鲍姆本意是证明：靠简单的句式变换，机器可以在完全不理解的情况下营造出“共情”的假象。没想到许多用户（包括他的秘书）真的对它产生了情感依赖，这就是ELIZA 效应。原书用 Python 复现了一个迷你版，并总结出三个局限：没有语义理解（“I am not happy”照样匹配 I am (.*)）、没有上下文记忆（无状态，每句独立处理）、规则扩展性差（规则一多，冲突和优先级就难以维护）。

    心智社会：没有中央大脑

    原书 2.3 节

    专家系统、SHRDLU、ELIZA 有一个共同点：自上而下，一个全知的中央处理器按统一规则处理一切。明斯基在 1986 年的《心智社会》里换了个问法：理解一个故事是一种能力，还是几十种心智过程协同的结果？他的回答是：“The trick is that there is no trick. The power of intelligence stems from our vast diversity, not from any single, perfect principle.”

    在他的理论里，“智能体”是极其简单、专门化、本身无心的过程，比如只会找线条的 LINE-FINDER、只会抓握的 GRASP。许多智能体组成机构（Agency），彼此通过去中心化的激活与抑制信号影响。复杂、有目的的行为不是谁预先规划的，而是从大量局部交互中涌现出来的：BUILD-TOWER 只会激活 BUILDER，BUILDER 只会循环激活 ADD-BLOCK，ADD-BLOCK 依次激活 FIND、GET、PUT-ON-TOP……GRASP 不知道什么是塔，BUILDER 不知道怎么控制手臂，塔却搭起来了。

    这为分布式人工智能和多智能体系统（MAS）奠定了概念基础：如果一个心智内部的智能来自协作，那多台机器之间能不能也协作出群体智能？它留下三条思想：去中心化控制、涌现式计算（蚁群、粒子群算法）、智能体的社会性（通信语言 ACL、契约网协议、协商、信任、组织结构）。今天 CAMEL、MetaGPT、CrewAI 的角色分工，都能在这里找到源头。

    原书习题 4 问：如果 GRASP 失效了会怎样？点任意一个节点让它失效，看影响沿树怎样传播。

    点一个节点让它失效。

    易混辨析：明斯基的“智能体” vs 今天的 LLM 智能体

    明斯基的智能体是无心的简单过程，智能只存在于整体的交互中；今天多智能体系统里的每个成员本身就是一个有推理能力的 LLM 智能体。所以现代 MAS 更像“一群聪明人开会”，而不是“一群神经元放电”。原书习题追问心智社会是否因此过时：它的思想（分工、去中心化、从交互中涌现）仍然适用，只是单元的粒度变大了。

    三次学习范式转变

    原书 2.4.1–2.4.3 节

    符号主义的教训和心智社会的启发指向同一个问题：如果智能无法被完全设计，能不能被学习出来？原书把答案分三步讲，每一步解决智能体的一个短板。

    联结主义（20 世纪 80 年代复兴）解决感知：知识以连接权重的形式分布式存储在大量简单神经元之间，靠反向传播从样本中自动调整；深度学习让智能体能直接从图像、声音、文本里理解世界。但“这张图里有什么”不等于“现在该做什么”。强化学习解决序贯决策：智能体在状态 S 下按策略 π 选行动 A，环境转移到新状态并给出奖励 R，目标是最大化累积回报而不是即时奖励（围棋里的弃子）；AlphaGo 靠数百万局自我对弈学会落子。但 RL 往往要从零开始、需要海量特定任务交互，缺少先验常识。预训练解决常识与先验：在互联网级文本上用自监督（预测下一个词）训练，再用少量标注数据微调；权重里压缩出一个隐式世界模型，以全新方式绕过了知识获取瓶颈。规模越过阈值后还出现了涌现能力：上下文学习（Few-shot / Zero-shot，不改权重就能做新任务）和思维链推理。

    原书把这段历史归为三大思潮：符号主义（西蒙、明斯基；SHRDLU、专家系统、深蓝）、联结主义（辛顿；反向传播、CNN、Transformer）、行为主义（试错学习；TD-Gammon、AlphaGo）。

    每张卡片说的是哪个学派？

    和已学系列对照：强化学习的状态、策略、回报在《强化学习的数学原理》系列有完整推导；预训练“猜下一个词”见《LLM 入门》01 篇。

    汇成 LLM 智能体

    原书 2.4.4–2.4.5 节，图 2.10

    到这里拼图齐了：符号主义贡献了逻辑推理和显式表示的框架，联结主义和强化学习贡献了学习与决策，预训练贡献了世界知识和通用推理。LLM 本身是联结主义的产物，却在智能体里扮演执行符号推理、工具调用、规划决策的“大脑”，形成神经与符号结合的架构。

    原书图 2.10 把 LLM 智能体画成几个模块的闭环：感知模块把环境输入变成观察；规划模块通过反思和自我批判把目标分解成步骤；LLM 作为中枢，结合记忆模块里的历史做推理，决定下一步的工具调用；执行模块解析指令、从工具箱里调用工具；工具结果和新的环境状态构成新观察，同时更新记忆，进入下一轮。和第一篇的五十行代码对照：那里的“记忆”就是 prompt_history，“规划”藏在模型的 Thought 里，“执行模块”就是那几行正则加字典查找。

    面试演练

    题目取自原书第 2 章习题与 Extra01

    设计一个“智能代码审查助手”：在 1980 年代、2015 年和今天分别怎么做？原书第 2 章习题 7

    • 符号主义时代：静态分析规则库（lint 规则、模式匹配危险调用）+ 专家规则；能抓已知模式，但无法概括实现逻辑、理解意图，规则写不完、维护成本高。
    • 深度学习时代：在标注数据上训练分类器（缺陷预测、代码异味检测）、序列模型生成简单注释；每个子任务单独训练，需要大量标注，泛化差，依旧写不出像样的审查意见。
    • LLM 智能体时代：按图 2.10 拆模块。感知（读 diff、相关文件、CI 结果）、规划（先总结改动再逐文件审查）、工具（检索代码库、跑测试和静态分析）、记忆（项目规范、历史审查意见）、执行（在 PR 上评论）。
    • 演进的关键：知识来源从手写规则到监督学习，再到预训练出的通用代码与语言理解；任务从“几乎不可能”变成“可行”。

    为什么说预训练解决了“知识获取瓶颈”？两种知识表示有什么本质区别？原书第 2 章习题 6

    • 瓶颈是什么：专家系统的知识要靠人访谈、提炼、编码成规则，昂贵、慢、无法规模化，且内隐知识说不出来。
    • 预训练怎么绕过：不再人工编码，而是让模型在海量文本上自监督学习，知识自动压缩进权重。
    • 表示的区别：符号主义是显式、离散、可读、可追溯的规则；预训练是隐式、分布式、连续的权重，泛化强但不可解释、会幻觉、知识有截止日期。
    • 带来的新问题：互联网数据有偏见、错误、过时信息；缓解靠数据清洗、对齐训练、检索增强（第 8 篇）。

    强化学习和监督学习在数据需求上有什么本质区别？在 LLM 训练里 RL 起什么作用？原书第 2 章习题 5；Extra01 · RLHF

    • 监督学习需要“输入—正确答案”的标注数据，学的是模仿；强化学习只需要环境给的奖励信号，在试错中学的是最大化长期回报，适合序贯决策。
    • 马里奥例子：监督学习需要人类玩家的“画面—按键”记录，只能学到人类水平；强化学习只需要分数和通关信号，可能超越人类，但需要大量交互。
    • 在 LLM 里：RLHF 用人类偏好训练奖励模型再优化策略，让模型有用、无害；RLVR / GRPO 用可验证奖励（数学答案、代码测试）提升推理能力（第 11 篇展开）。

    回扣开头的三个问题

    先自己答，再点开
    1. 符号主义的根本困难？预训练为何解决了知识获取瓶颈？

    两类困难：知识层面是知识获取瓶颈和常识问题（规则要人工提炼，内隐知识说不出，常识无穷无尽）；逻辑层面是框架问题和脆弱性（无法高效表达动作后哪些不变，规则外的情况就失灵）。预训练不再人工编码知识，而是在海量文本上自监督学习，把知识隐式压缩进权重，所以绕过了人工提炼这一步。

    2. 心智社会留下了哪些思想？

    智能来自大量简单、无心的智能体组成的机构之间的交互，而不是单一完美的原理；复杂行为从局部交互中涌现。它启发了分布式 AI 与多智能体系统的三条主线：去中心化控制、涌现式计算、智能体的社会性（通信语言、交互协议、协商、信任、组织结构）。

    3. 三次学习范式各解决了什么？怎样汇成 LLM 智能体？

    联结主义解决感知（从原始数据中学模式），强化学习解决序贯决策（从交互奖励中学策略），预训练解决常识与先验（从海量文本中学世界知识，并涌现出上下文学习和思维链）。LLM 是联结主义的产物，却在智能体里执行符号推理、规划和工具调用，与记忆、规划、执行模块组成感知—思考—行动闭环。
