语言模型：从数数到神经网络

原书 3.1.1 节

语言模型的任务是给一个词序列算概率。按链式法则，句子概率等于每个词在前文条件下的概率连乘，但“前面所有词”这个条件太长，语料里根本数不到。N-gram 用马尔可夫假设砍掉历史：只看前 N−1 个词。Bigram 只看前一个词，概率用最大似然估计，也就是数数：P(wi|wi−1) = Count(wi−1, wi) / Count(wi−1)。

N-gram 有两个致命缺陷：数据稀疏（没见过的组合概率为 0，平滑只能缓解）和泛化差（见过一万次 agent learns，也推不出 robot learns，因为它不知道 agent 和 robot 意思相近）。2003 年 Bengio 的神经网络语言模型用词嵌入解决泛化：每个词是高维空间里的一个点，语义相近的词位置相近，用余弦相似度衡量，甚至能做 king − man + woman ≈ queen 这样的类比。但它和 N-gram 一样只看固定窗口。RNN 用一个不断更新的隐藏状态当短期记忆，理论上能看无限长的历史；可序列长度就是网络深度，梯度反向传播时连乘会消失或爆炸，学不到长距离依赖。LSTM 加了一条细胞状态通路和遗忘门、输入门、输出门，有选择地保留和丢弃信息，缓解了这个问题。

Transformer 与 Decoder-Only

原书 3.1.2–3.1.3 节

RNN 必须一步步算：第 t 步要等第 t−1 步，无法并行，模型和数据都撑不大。2017 年的 Transformer 彻底扔掉循环，只用注意力捕捉依赖，所有位置可以同时计算。原始设计是机器翻译用的编码器—解码器：编码器“理解”整个输入，解码器参考前文和编码器的理解逐词“生成”。

自注意力给每个词元三个角色：Q（我在找什么）、K（我能被怎样找到）、V（我携带的内容），都由词向量乘可学习矩阵得到。读到 “it” 时，用 it 的 Q 和所有词的 K 点积打分，除以 √dk 防止数值过大，softmax 成权重，再对 V 加权求和：Attention(Q, K, V) = softmax(QKT/√dk)V。多头是把这件事切成 h 份并行做，每个头关注一种关系（指代、时态、从属），最后拼接。每层还有逐位置前馈网络（先扩到约 4 倍维度再缩回，所有位置共享权重）、残差连接（梯度可以绕过子层）和层归一化。注意力本身不分先后，“agent learns”和“learns agent”对它一样，所以要加位置编码（原论文用正余弦公式）。

GPT 的想法更简单：语言的核心任务不就是预测下一个词吗？于是扔掉编码器，只留解码器，自回归地生成：预测一个词，接到输入末尾，再预测下一个。训练时整段文本并行送入，靠因果掩码防止偷看：softmax 之前把当前位置之后的分数设为极大负数，权重就变成 0。Decoder-Only 的优势：训练目标统一（只有下一个词，适合海量无标注数据），结构简单易扩展，天然适合生成。这也是它能当智能体大脑的原因：Agent 每一轮的 Thought 和 Action，都是这样一个词一个词“接龙”出来的。

采样参数：改的是分布，不是模型

原书 3.2.1 节（1）

模型每一步输出的是词表上每个词元的分数（logits），softmax 之后得到概率分布，再从中采样一个。采样参数不改模型，只“重新调整”或“截断”这个分布。Temperature 把 logits 除以 T：T 小于 1 让分布变陡、更确定，大于 1 变平、更发散，T → 0 等于总是选最高的（贪心）。Top-k 只保留概率最高的 k 个候选再归一化，k = 1 就是贪心。Top-p（核采样）从高到低累加概率，到达 p 为止，候选数随分布形状自动变化：分布尖时只剩一两个，分布平时保留很多，比固定 k 更能适应长尾。

原书给的执行顺序是温度 → Top-k → Top-p，同时设置时候选集是两者的交集，一般二选一即可。温度为 0 时 Top-k、Top-p 都无关紧要；Top-k 为 1 时温度和 Top-p 也无关紧要。经验范围：0 到 0.3 用于事实问答、计算、代码；0.3 到 0.7 用于日常对话和常规写作；0.7 以上用于创意发散。做 Agent 时，负责输出 Action、JSON、工具参数的那一步通常用低温，格式更稳；负责头脑风暴或生成多个候选方案的步骤可以调高。

提示工程：和大脑沟通的语言

原书 3.2.1 节（2）–（5）

按给模型的示例数量，提示分零样本（只给指令）、单样本（给一个完整示例）、少样本（给多个覆盖不同情况的示例，让模型看清任务的边界）。这几种能工作，靠的是第 2 篇说的上下文学习：不改权重，只靠输入里的示例。

还要分清模型类型。早期 GPT-3 是文本补全模型，只会续写，你得用少样本把任务“演”出来（“英文：Hello / 中文：你好 / 英文：How are you? / 中文：”）。指令调优用大量“指令—回答”数据继续微调，今天日常用的 ChatGPT、DeepSeek、Qwen 都是这类模型，可以直接下指令。基础技巧：角色扮演（“你是一位资深 Python 专家”）约束风格和知识范围；上下文示例规定复杂输出格式（比如严格的 JSON）；思维链在复杂推理题后加一句“请一步一步地思考”，先写推理再给答案，准确率更高，也便于检查。

对 Agent 来说，这些不是孤立技巧：第一篇的系统提示词就同时用了角色扮演（旅行助手）、格式示例（Thought / Action 模板）和思维链（Thought 本身就是让模型先想再动）。下一篇的 ReAct、Plan-and-Solve、Reflection，本质上都是更有结构的提示模板。

每段提示用的是哪种技巧？

易混辨析：少样本提示 vs 指令调优 vs 微调

少样本提示只改输入，不改权重，每次调用都要带上示例（占 Token）；指令调优是模型厂商做的一次性微调，让模型学会“听指令”这件通用的事；任务微调是你用自己的领域数据改权重，让模型擅长某个具体任务。顺序上先试提示，提示做不到再考虑微调（第 11 篇讲 SFT）。

分词：模型看到的不是字

原书 3.2.2 节

模型只认数字，文本要先切成词元（Token）再转成 ID。按词切，词表爆炸，还有未登录词（OOV），look / looks / looking 互不相干；按字符切，词表小、无 OOV，但单个字符没什么意义，学习效率低。现代 LLM 用子词分词折中：常见词整个保留，罕见词拆成有意义的片段（Tokenization → Token + ization）。

最主流的是 BPE（字节对编码），GPT 系列在用：从字符开始，反复统计相邻词元对的频率，把最高频的一对合并成新词元，直到词表达到预设大小。衍生算法有 WordPiece（BERT 用，合并标准改成“最能提升语料似然”的一对）和 SentencePiece（Llama 用，把空格当普通字符，分词可逆、与语言无关）。

原书强调，对 Agent 开发者重要的不是算法细节，而是三个后果：上下文窗口按 Token 算，同一段话中英文、不同分词器下 Token 数差很多；API 按 Token 计费；以及怪异行为：2 + 2 算得对，2+2 可能出错，大小写不同会切成完全不同的序列。

选模型，认局限

原书 3.2.3–3.3 节

原书用 Hugging Face Transformers 在本地跑了一个 0.5B 的 Qwen 对话模型：AutoTokenizer 加载分词器，apply_chat_template 把 messages 套成模型认识的对话模板，generate 产出 Token ID，截掉输入部分后 decode 回文本。这条链路值得记住，因为它说明了 API 背后发生的事：messages 先被模板化成一个长字符串，再分词、生成、解码。

选模型不是越大越好，而是权衡：性能与能力（推理、代码、多语言各有所长，可参考公开排行榜）、成本（闭源按 Token 计费，开源是硬件和运维）、延迟、上下文窗口、部署方式（API 便捷但数据出境，本地可控但门槛高）、生态与工具链、可微调性、安全与伦理。原书还列了当时主流的闭源与开源模型，版本更新太快，这里不抄，只记选型维度。

缩放法则：损失与参数量、数据量、计算量在对数坐标下呈平滑幂律，持续按比例投入就能可预测地变好。Chinchilla 定律（DeepMind 2022）修正了“越大越好”：给定算力下参数量和数据量有最优配比，最优模型更小但要用多得多的数据。规模过阈值后出现涌现能力（思维链、指令遵循、多步推理），所以复杂的自主规划需要足够大的模型。

幻觉是生成内容与事实、输入或上下文矛盾，分事实性（与现实不符）、忠实性（摘要、翻译没忠实于原文）、内在（与输入直接矛盾）。成因：训练数据有错、自回归只预测下一个最可能的词而没有事实核查、复杂推理中途出错。另有知识截止和偏见。缓解分三层：数据（清洗、RLHF）、模型（让模型表达不确定性）、推理（RAG、多步推理与验证、调用外部工具）。推理层的三招，恰好就是 Agent 的记忆、反思和工具。

解释自注意力机制。它为什么比 RNN 更适合处理长序列？Extra01 · LLM 八股第 1 题

  • 机制：每个词元经线性变换得到 Q、K、V；用 Q 与所有 K 点积、除以 √dk、softmax 得权重，对 V 加权求和得到融合全局上下文的新表示。
  • 为何更好：任意两个位置一步直达，路径长度为 1，不会像 RNN 那样经过多步连乘导致梯度消失；所有位置并行计算，能充分利用 GPU。
  • 代价：注意力矩阵是序列长度的平方，长上下文的显存和计算开销大；本身不含位置信息，需要位置编码。

解释 Greedy、Beam Search、Top-K、Top-P 解码策略的原理和优缺点。Extra01 · LLM 八股第 7 题

  • Greedy：每步取最高概率词，确定、快，但容易重复、陷入局部最优。
  • Beam Search：每步保留 b 条得分最高的部分序列，适合翻译等有标准答案的任务；开放生成中容易平淡、重复。
  • Top-K：只在前 k 个候选里按概率采样；k 固定，分布尖时可能混入低质量词，分布平时又可能截掉好词。
  • Top-P：在累积概率达到 p 的最小集合里采样，候选数自适应，更适合长尾分布。温度在它们之前调整分布的陡峭程度。

为什么不直接用字符或单词做输入单元？BPE 解决了什么？原书第 3 章习题 3；Extra01 · LLM 八股第 8 题

  • 按词：词表爆炸、OOV、词形变化之间没有关联、低频词学不好。
  • 按字符：序列变长、单个字符语义弱、学习效率低。
  • BPE：从字符起步，反复合并最高频的相邻对，常见词成整体、罕见词拆成子词，既控制词表大小又没有 OOV。
  • 和 WordPiece 的区别：BPE 按频率合并，WordPiece 按“合并后语料似然提升最大”合并。

论文辅助阅读智能体：论文超过上下文窗口怎么办？怎样保证忠于原文？原书第 3 章习题 6

  • 超长：按章节切块，先生成各节摘要再汇总（Map-Reduce）；问答时用 RAG 只检索相关段落；或选长上下文模型，但仍要控制成本。
  • 忠实：要求回答附原文引用（页码、段落），生成后做引用核对；低温度；不确定时允许说“原文未提及”；数字、公式直接从原文抽取而非生成。
  • 多篇比较：先对每篇抽取统一结构的字段（问题、方法、数据、结论），再在结构化结果上比较。

回扣开头的三个问题

先自己答，再点开
1. 每一步演进解决了什么？为什么是 Decoder-Only？

N-gram 用马尔可夫假设和计数估概率，但稀疏、不泛化；神经网络语言模型用词嵌入解决泛化，但窗口固定；RNN 用隐藏状态记任意长历史，但梯度消失；LSTM 用细胞状态和门控缓解；Transformer 用注意力让任意位置一步直达并且可以并行。Decoder-Only 只做“预测下一个词”：训练目标统一、适合海量无标注数据，结构简单易扩展，自回归方式天然适合生成，因果掩码保证训练与生成一致。

2. 三个采样参数怎样改分布？Agent 怎么设？

Temperature 把 logits 除以 T，调整分布陡峭程度；Top-k 只保留前 k 个候选；Top-p 保留累积概率达到 p 的最小集合，候选数自适应。顺序是温度、Top-k、Top-p。Agent 中输出 Action、JSON、工具参数的步骤用低温求稳定，需要发散、生成多个候选的步骤可以调高。

3. 分词、上下文窗口、幻觉分别在哪里出问题？

分词：窗口和计费都按 Token 算，中文、代码、数字的 Token 数可能远超预期；空格、大小写差异会导致异常行为，影响输出解析。上下文窗口：长对话、长文档、工具返回会撑爆窗口，需要截断、摘要、检索（第 8、9 篇）。幻觉：模型可能编造工具参数、不存在的实体或 Observation，需要 RAG、工具调用、验证与反思来压制。
