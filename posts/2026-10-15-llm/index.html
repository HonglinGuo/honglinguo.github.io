01 说到底，它只是在猜下一个词20 条概念 · 15 条公式与要点

概念

token
模型读写文字的最小单位，可能是一个字、一个词，也可能是一个词的一部分。
词表 vocabulary
所有 token 的固定清单，每个 token 对应一个整数编号；大模型的词表通常有 5 万到 25 万项。
分词 tokenization
按词表把一段文字切成 token 序列、再换成编号的过程。
BPE
一种常用的建词表方法：从单个字符出发，反复把语料里最常相邻出现的一对合并成新 token。
语言模型
给定前文，输出“下一个 token 的概率分布”的程序。
概率分布
给词表里每个 token 一个 0 到 1 之间的数，全部加起来等于 1。
条件概率
在已知前文的条件下某个 token 出现的可能性，记作 P(下一个 | 前文)。
候选
概率表里的每一项，即下一步可能出现的某个 token。
自回归生成
每次只生成一个 token，接到前文末尾，再把整段当作新输入继续预测。
结束标记
词表里一个特殊 token，模型选中它就表示这段话写完了。
上下文
模型当前能看到的全部文本，包括提示词和它已经写出的内容。
提示词 prompt
用户或系统给出的开头文字，是生成循环的第一段前文。
图灵测试
只通过文字交流，如果裁判反复测试也分不清哪个是机器，就认为机器表现出了人的智能。
行为标准
只看输出像不像人，不问内部怎么实现。
分布接近
模型的概率表与人写作时的概率表越接近，写出的文字越难与人区分。
模仿游戏
图灵 1950 年提出的原始说法：裁判通过打字与看不见的人和机器对话。
预测即理解的压力
要把下一个词猜准，模型必须把文字背后的知识、逻辑、常识和情绪也学进去。
知识
关于世界的事实，例如地理、人物、日期。
推理
把多条信息串起来得出新结论的能力。
常识
人人默认知道、文本里很少明说的道理。

公式与要点

生成一个 token = 整个模型完整算一遍
所以 token 越少，生成越快、越省钱。
常见词并成一块，生僻词拆成碎片
同样一句话，在不同模型里的 token 数可能不同。
模型看不到 token 内部的字母
这是它数字母、做逐位运算容易出错的根源。
Σi P(tokeni
前文) = 1 | 一张合法的概率表，所有候选加起来必须是 1。
前文约束越强，分布越尖
尖的分布好猜（熵低），平的分布难猜（熵高）。
这些概率是从人写的海量文本里学出来的
表达的是“人在这里通常会接什么”。
前文 → 概率表 → 挑一个 → 接上 → 重复
聊天回复就是这个循环跑几百次。
写出的 token 不会撤回
一步走偏，后面只能顺着它往下写。
停止条件
选中结束标记，或达到预设的最大长度。
最佳裁判只看一个词的命中率 = ½ + ½·TV(p, q)
TV 是两张概率表的“总变差距离”，重合越多越接近 50%。
看的文字越多，差异越会累积
所以测试需要长时间对话。
“分不出”不等于“真理解”
机器是否理解，至今仍有争论。
同一个训练目标，逼出多种能力
没人单独教它推理，猜准的压力让它不得不学。
能力来自数据里藏着的规律
数据里没有的东西，它也学不到。
“分不出”只是行为标准
能不能算真正的理解，学界仍有争论。
02 猜得有多准，用 bit 来量24 条概念 · 21 条公式与要点

概念

信息
能消除不确定性的东西。
bit
区分两个等可能选项所需的信息量，也就是“对半砍一刀”。
二分提问
每次把剩余候选分成数量相等的两组来问，每问恰好拿到 1 bit。
对数 log2
问“要对半砍几次”：log28 = 3，因为 8 砍 3 次剩 1。
信息量（自信息）
一个结果发生时带来的信息，概率越小信息越多。
惊讶程度
信息量的直观含义：越出乎意料，信息越多。
必然事件
概率为 1 的结果，知道它发生不带来任何信息。
nat
用自然对数 ln 计量的信息单位，训练代码里最常见。
熵 entropy
各结果信息量按其概率加权的平均值，衡量一个随机事件平均有多难猜。
均匀分布
所有结果概率相同，同样多候选时熵最大。
确定性分布
某个结果概率为 1，熵为 0。
加权平均
每种结果的值乘以它的概率再相加；熵就是信息量的加权平均。
无损压缩
能被完整还原的编码方式。
前缀码
任何一个码字都不是另一个码字开头的编码，接收方可以逐位解码不会歧义。
霍夫曼编码
反复把概率最小的两项合并，得到平均码长最短的前缀码。
压缩即理解
能把数据压得越短，说明掌握的规律越多；这是一种研究视角，不是已证明的定理。
交叉熵 cross-entropy
真实按 p 出现、却按模型的 q 来编码时，平均每个结果花费的 bit 数。
KL 散度
交叉熵减去熵，即估错概率多花的部分，永远不小于 0。
困惑度 perplexity
2 的交叉熵次方，表示模型平均像在几个等可能选项里犹豫。
损失函数
训练时要压低的那个数；语言模型用的就是交叉熵。
香农猜字实验
让人逐字母猜一段被遮住的文本，记录每个字母猜了几次，用来估计语言的熵。
猜测序号编码
只传“第几次猜中”的记录，对方用相同的预测者就能还原原文。
上下文
已知的前文；知道得越多，下一个字越好猜。
上界
模型在真实文本上的交叉熵不会低于语言的真实熵，因此是它的一个上界。

公式与要点

N 个等可能候选需要 log2N bit
8 个要 3 bit，16 个要 4 bit，64 个要 6 bit。
一次“是 / 否”回答最多带来 1 bit
所以任何问法平均都至少要问 log2N 次。
一问拿到的信息 = log2(问前候选数 ÷ 问后候选数)
问得偏，拿到的就少于 1 bit。
I(x) = −log2 p(x)
单位是 bit；用自然对数时单位是 nat。
p = ½ → 1 bit，p = ⅛ → 3 bit
概率每减半，信息量加 1 bit。
1 nat ≈ 1.44 bit
训练代码里常用自然对数，只差一个固定倍数。
H(X) = −Σ p(x) · log2 p(x)
熵的定义。
公平硬币 H = 1 bit；正面 90% 时 H ≈ 0.469 bit
越偏越好猜。
0 ≤ H ≤ log2N
下界在完全确定时取到，上界在 N 个结果等可能时取到。
罕见结果信息量大，但占比小
所以拉不高平均值。
平均码长 L ≥ H
熵是任何无损编码平均长度的下限（香农信源编码定理）。
霍夫曼：H ≤ L < H + 1
最优前缀码离熵不到 1 bit。
常见的配短码，少见的配长码
理想码长就是 −log2 p。
H(p, q) = −Σ p(x) · log2 q(x)
p 负责加权，q 负责定价。
H(p, q) = H(p) + KL(p‖q) ≥ H(p)
只有 q = p 时相等。
PPL = 2H(p, q)
交叉熵 3 bit 对应困惑度 8。
实际计算：对每个位置取 −log q(真实下一个 token) 再求平均
不需要知道真实分布 p。
自信地猜错比什么都不懂更贵
常见结果被分到了很长的码。
英文 27 种符号乱猜：log227 ≈ 4.75 bit
不用任何规律时的难度。
有约 100 个字母上下文：约 0.6–1.3 bit / 字母
香农 1951 年的估计。
模型越好，这个上界压得越低
也就越接近语言本身的熵。
03 神经网络：一堆会弯折的加法21 条概念 · 17 条公式与要点

概念

神经元
把输入加权求和、加上偏置，再经过一个非线性函数输出一个数。
权重 w
每个输入对结果的影响大小和方向。
偏置 b
固定加上的一个量，决定神经元在哪里“打开”。
ReLU
最常用的非线性函数：负数变 0，正数原样输出。
参数
所有权重和偏置的统称，训练就是在调它们。
层
许多神经元并排，接收同一组输入。
神经网络
一层层叠起来，上一层的输出是下一层的输入。
非线性 / 激活函数
每层加权求和之后的“弯折”，让网络能表示弯曲的关系。
隐藏层
输入层和输出层之间的层，它的输出不直接给人看。
logits
最后一层给每个候选 token 打的原始分数，可正可负。
Softmax
把一组分数变成概率：先取指数，再除以总和。
平移不变性
所有分数加上同一个数，Softmax 结果不变。
指数函数 ex
永远为正，且 x 越大增长越快，用来放大分数之间的差距。
通用逼近定理
神经元足够多时，即使只有一个隐藏层，网络也能以任意精度逼近任意连续函数。
帐篷函数
用三个 ReLU 拼成的尖顶：两边为 0，中间一个峰。
存在性定理
只保证好参数存在，不保证能找到。
折线逼近
用许多首尾相连的直线段去贴合一条曲线，段越多贴得越紧。
深度
网络的层数。
深度优势
同样多的神经元，叠深能表示的函数远比铺宽复杂。
层级表示
低层处理表层模式，高层在其上组合出语义和推理。
宽度
每层神经元的数量。

公式与要点

y = ReLU(w1x1 + … + wnxn + b)
一个神经元的完整公式。
ReLU(z) = max(0, z)
只有一个拐点。
单输入时，开关位置 x = −b / w
打开后的斜率是 w。
线性套线性还是线性：3(2x + 1) − 2 = 6x + 1
没有激活函数，叠多少层都等价于一层。
每个 ReLU 最多贡献一个拐点
拐点多了，折线就能弯成复杂形状。
拐点越多，能拟合的形状越复杂
这正是加神经元、加层的意义。
qi = esi / Σj esj
Softmax 公式。
每个 qi > 0，Σ qi = 1
保证是合法概率，猜错时交叉熵也不会无穷大。
只有分数差决定概率
差 1 分，概率比约为 e ≈ 2.72 倍。
最后一层不加 ReLU
否则负分全变 0，分不出高低。
ReLU(x) − 2·ReLU(x−1) + ReLU(x−2)
在 x = 1 处取峰值 1、两侧为 0 的帐篷。
帐篷越多越窄，折线越贴近目标
每顶帐篷用 3 个 ReLU。
定理没回答的三件事
需要多少神经元、参数怎么找、能否推广到没见过的数据。
L 层折纸网络：2L 个神经元，2L 段折线
段数随层数指数增长。
单层要表示同样的折线，至少 2L − 1 个神经元
一层里每个神经元只贡献一个拐点。
GPT-3：96 层；Llama 3 8B：32 层
真实大模型都很深。
代价：越深越难训练
要靠残差连接和归一化来解决。
04 训练：往下坡走，把错摊回去25 条概念 · 21 条公式与要点

概念

梯度
参数微微变化时损失跟着变化的比例，指出往哪个方向调能让损失上升。
梯度下降
每一步都把参数往梯度的反方向挪一点，让损失下降。
学习率
每一步迈多大；太小走得慢，太大会震荡甚至发散。
局部最小值
周围都比它高的低点，不一定是全局最低。
独热答案
真实下一个 token 记为 1，其余记为 0 的向量。
预测减答案
Softmax 配交叉熵时，每个分数的梯度恰好等于“概率 − 答案”。
批次 batch
每次更新前同时计算的一批文本，梯度取平均后再更新。
交叉熵损失
对真实 token 取 −log q；预测越准，损失越接近 0。
反向传播
先正向算出结果，再从损失出发逐层往回，用链式法则算出所有参数的梯度。
链式法则
复合函数的导数等于各层局部导数相乘。
局部系数
每一层输出对输入的导数，梯度回传时要乘上它。
计算图
把模型拆成一步步运算连成的图，正向沿图算值，反向沿图传梯度。
梯度消失
层数多时连乘许多小于 1 的系数，前面的层几乎收不到梯度。
梯度爆炸
连乘许多大于 1 的系数，梯度变得极大，训练失控。
残差连接
每层输出“输入 + 本层的修改”，给梯度留一条直通路。
残差流
贯穿所有层的那条向量通道，各层从中读取、再把修改加回去。
归一化
每层计算前把向量调回标准的数值范围。
LayerNorm
对每个位置的向量减去均值、除以标准差，再乘上可学习的缩放、加上偏移。
RMSNorm
不减均值，只除以均方根，更省计算，效果相近。
Pre-Norm
把归一化放在子层之前，训练更稳定，现代大模型的标准做法。
过拟合
在训练数据上表现很好，在没见过的数据上表现变差，相当于背答案。
泛化
在没见过的数据上也表现良好，相当于学会了方法。
验证集
不参与训练、只用来检查的那部分数据。
欠拟合
训练和验证误差都高，模型太小或训练不够。
最小描述长度
能用最短描述说清数据的规律，往往泛化最好。

公式与要点

θ ← θ − η · ∂L/∂θ
参数更新公式，η 是学习率。
例：L = (3w − 12)²，∂L/∂w = 18w − 72
本节演示用的损失和梯度。
梯度为负就把参数调大，为正就调小
减号就是“下坡”。
Adam 优化器
参考近几步梯度的平均方向，并给每个参数单独调步长。
∂L/∂si = qi − yi
正确答案的梯度为负（被拉高），其他为正（被压低）。
越被看好的错误答案，被压得越狠
压低的幅度正比于它原来的概率。
所有句子共用一套参数
普遍有用的调整被反复加强，个别噪声互相抵消。
∂L/∂a = ∂L/∂y · ∂y/∂h · ∂h/∂a
链式法则：沿路径把局部导数乘起来。
算全部梯度 ≈ 正向计算量的 2 倍
所以训练一步约是推理一步的 3 倍。
每层只需自己的输入和后面传来的梯度
框架（如 PyTorch）会自动完成。
0.9100 ≈ 2.7 × 10−5；1.1100 ≈ 1.4 × 104
连乘的威力。
y = x + F(x)，局部系数 = 1 + F′
即使 F′ 很小，也不会乘到 0。
xL = x0 + F1 + … + FL
最终输出 = 原始输入 + 每层修改之和。
ResNet（2015）用残差把网络训到 152 层
今天的大语言模型每层都带残差。
LN(x) = γ · (x − μ) / σ + β
μ 是均值，σ 是标准差。
RMS(x) = √(Σxi² / n)

05 Transformer：每个词都去别处找线索26 条概念 · 23 条公式与要点

概念

嵌入向量
每个 token 对应的一串可学习的数，用来代替没有意义的编号。
嵌入表
词表大小 × 向量维度的大矩阵，查表就能把编号换成向量。
点积
两个向量对应位置相乘再相加，方向越接近越大。
余弦相似度
点积除以两个向量长度之积，只看方向不看长度。
近似正交
两个方向的夹角接近 90°，点积接近 0，几乎互不干扰。
叠加 superposition
在 d 维空间里放远多于 d 个概念，每个占一个近似正交的方向。
干扰噪声
叠加的代价：读一个概念时会混进一点其他概念。
维度
向量里数字的个数；大模型通常是几千维。
注意力
每个位置按相关程度给前文各位置分配权重，再把它们的信息加权平均收集过来。
查询 Q
当前位置“想找什么”。
键 K
每个位置“我这里有什么”，用来和查询比对。
值 V
被关注时实际交出去的内容。
多头注意力
并行多组独立的 Q、K、V，各自关注不同关系，结果拼接后再混合。
归纳头
一类注意力头：看到 A 时去找上次 A 后面的 B，从而预测 B。
因果掩码
让每个位置只能看到自己和之前的位置，不能偷看未来。
解码器
Transformer 中按顺序生成的那一半；语言模型只用它。
并行训练
一段文本算一遍，每个位置同时练习预测自己的下一个 token。
下三角矩阵
因果掩码的形状：第 i 行只有前 i 列可见。
位置编码
让模型知道 token 顺序的信息；注意力本身对顺序不敏感。
正弦位置编码
原始 Transformer 的做法：把按位置算出的正弦、余弦向量加到 token 向量上。
旋转位置编码 RoPE
计算注意力前，按位置把查询和键各自旋转一个角度。
相对位置
两个 token 相隔多远，比它们的绝对位置更有用。
Transformer 块
注意力 + 前馈网络两个子层，各自前置归一化、外套残差连接。
前馈网络 FFN
每个位置独立的“加权求和 + 弯折”，先放宽到约 4 倍再压回。
SwiGLU
现代模型常用的带门控的前馈网络变体。
键-值记忆
一种解释：前馈层识别输入模式，再提高相应后续 token 的分数。

06 从一张概率表，到一个聊天助手29 条概念 · 23 条公式与要点

概念

贪心解码
每步都选概率最高的 token，稳定但容易单调重复。
随机采样
按概率抽签，多样但可能抽中长尾里的离谱词。
Top-k
只在概率最高的 k 个候选里抽。
Top-p（核采样）
从高到低累加到概率 p 为止，只在这些候选里抽，候选数随情况变化。
温度
先把分数除以 T 再做 Softmax，控制分布的尖锐程度。
预训练
在海量普通文本上学“预测下一个 token”，得到基座模型。
基座模型
知识丰富但只会续写，不知道要扮演回答者。
后训练
把基座模型变成助手的一系列训练的统称。
监督微调 SFT
用“指令 + 优质回答”的示范继续训练，通常只对回答部分算损失。
对话模板
用特殊标记把系统提示、用户、助手的话拼成一段连续文本。
推理强化学习
在可自动判对错的题目上只奖励最终正确，模型自己学会先推理再作答。
RLHF
基于人类反馈的强化学习：收集偏好比较 → 训练打分模型 → 让助手往高分方向优化。
奖励模型
用人的“哪个更好”数据训练出来、给回答打分的模型。
奖励投机
模型钻打分模型的空子，分数上涨但真实质量下降。
KL 约束
在奖励里扣掉“偏离原模型多远”，防止优化走偏。
DPO
跳过奖励模型，直接用“好 / 差”回答对调整模型的偏好对齐方法。
工具调用
模型写出一段约定格式的调用文字并停下，由外部程序执行，再把结果作为文字接回上下文。
智能体 Agent
让“思考 → 调用工具 → 看结果”的循环自动运行多轮，直到完成任务。
多模态输入
把图片切成小块并转成向量，与文字 token 一起送入同一个 Transformer。
系统提示词
放在对话最前面的说明文字，常用来告诉模型有哪些工具、怎么调用。
规模定律
交叉熵随参数量、数据量、算力的增加按幂律平稳下降。
算力最优
在固定计算预算下，使损失最低的参数量与数据量搭配。
不可约损失
无论模型多大、数据多多都消不掉的部分，对应文本本身的熵。
幂律
规模每扩大同样的倍数，损失就按大致固定的比例下降；在双对数坐标上近似一条直线。
幻觉
生成流畅、自信但与事实不符的内容。
知识截止
模型只知道训练数据收集之前的信息。
上下文窗口
模型一次能处理的最大 token 数。
迎合 sycophancy
倾向于同意用户，即使用户是错的。
反转诅咒
学会“A 是 B”不代表能答出“B 是 A”。
