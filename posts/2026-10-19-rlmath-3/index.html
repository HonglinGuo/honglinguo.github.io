最优策略一定存在，而且可以算出来

强化学习的终极目标是找到最优策略。可“最优”是什么意思？它存不存在、唯不唯一、是确定的还是随机的？这一章用一个方程回答所有问题：贝尔曼最优方程。它看起来比贝尔曼方程更难（多了一个 max、两个未知数），但它的右端是一个收缩映射——于是解存在、唯一、能用最简单的迭代求出来，而解出来的就是最优状态值和最优策略。

本系列是教材《强化学习的数学原理（Mathematical Foundations of Reinforcement Learning）》（赵世钰（Shiyu Zhao）著，西湖大学；Springer Nature 与清华大学出版社 2025 年出版，作者在 GitHub 免费公开全书 PDF 与课件，本笔记依据仓库中 2025 年 7 月更新的英文 PDF（已含勘误））的学习笔记。原书仓库没有附带开源许可证，版权归作者与出版社所有；这里不转载原文和插图，而是按“先说清楚它解决什么问题、再动手算、最后记下来”的顺序用自己的话重讲，网格世界、算法与图都在浏览器里重新实现和手绘。公式、定义、例子与参数以原书为准，标注了对应的节号和页码；页面里的模拟结果标注“示意”，复现出原书图中数值的地方标注“原书数据”。

从一个例子出发：怎么改进策略

原书 3.1 节 · 第 36–37 页

原书图 3.2：2×2 网格，s2 是禁区，s4 是目标，策略在 s1 向右（进禁区），其余都对。直觉上把 s1 改成向下就好。数学上怎么得出这个结论？

两步。先评估：γ = 0.9 时解贝尔曼方程得 vπ(s2) = vπ(s3) = vπ(s4) = 10，vπ(s1) = −1 + 0.9 × 10 = 8。再看 s1 的五个动作值：q(s1, a1) = −1 + γv(s1) = 6.2，q(s1, a2) = 8，q(s1, a3) = 0 + γv(s3) = 9，q(s1, a4) = 6.2，q(s1, a5) = 7.2。向下的动作值最大，把策略改成选它。

这就是许多强化学习算法的基本思想：评估当前策略 → 选动作值最大的动作。但这个例子太简单，策略只在一个状态上不好。如果到处都不好，这样改还能保证变好吗？最优策略一定存在吗？这一章就回答这些问题。

最优策略与贝尔曼最优方程

原书 3.2–3.3.2 节 · 第 37–40 页

定义 3.1：如果对所有状态 s 和任意其他策略 π 都有 vπ*(s) ≥ vπ(s)，π* 就是最优策略，它的状态值叫最优状态值。注意这是逐状态的比较——要求一个策略在每个格子上都不输。这个定义立刻引出四个问题：存在吗？唯一吗？是随机的还是确定的？怎么求？

分析工具是贝尔曼最优方程（BOE）：

v(s) = maxπ(s) Σa π(a|s) q(s, a)，q(s, a) = Σr p(r|s, a) r + γΣs′ p(s′|s, a) v(s′)原书式 (3.1)

它和贝尔曼方程只差一个 max，但现在有两个未知数：v 和 π。原书用两个小例子说明怎么“一个方程解两个未知数”。例 3.1：x = maxy(2x − 1 − y2)。不管 x 是多少，右边的最大值总在 y = 0 取到，等于 2x − 1；再解 x = 2x − 1 得 x = 1。先把 max 里的变量解掉，再解剩下的方程。例 3.2：在 c1 + c2 + c3 = 1、ci ≥ 0 的约束下最大化 Σciqi，最优解是把全部权重放在最大的 qi 上。套到 BOE：Σaπ(a|s)q(s, a) ≤ maxa q(s, a)，等号在 π 把概率 1 给 a* = argmaxa q(s, a) 时取到。

于是 BOE 化为 v(s) = maxa q(s, a)。写成矩阵形式：v = maxπ(rπ + γPπv) ≐ f(v)（max 逐元素进行）。这是一个关于 v 的非线性方程 v = f(v)，下一节用收缩映射定理来分析它。

拖动三个权重，验证“凸组合 ≤ 最大值”；看哪种 c 能让它取到等号。

收缩映射定理

原书 3.3.3–3.3.4 节 · 第 40–46 页

考虑 f: ℝd → ℝd。满足 f(x*) = x* 的点叫不动点。如果存在 γ ∈ (0, 1) 使 ‖f(x1) − f(x2)‖ ≤ γ‖x1 − x2‖ 对任意 x1、x2 成立，f 就是收缩映射——它把任意两点之间的距离至少缩小一个固定比例。原书举的例子：f(x) = 0.5x；f(x) = Ax 且 ‖A‖ ≤ γ < 1；f(x) = 0.5 sin x（由中值定理 |0.5 cos x3| ≤ 0.5）。

收缩映射定理（定理 3.1）：若 f 是收缩映射，则 x = f(x) 的不动点存在、唯一，并且迭代 xk+1 = f(xk) 从任意初值出发都指数快速收敛到它。证明的骨架（原书框 3.1）：相邻两步的距离 ‖xk+1 − xk‖ ≤ γk‖x1 − x0‖；只有“相邻距离 → 0”还不够（√n 就是反例），要进一步证明 ‖xm − xn‖ ≤ γn/(1 − γ) · ‖x1 − x0‖，所以是柯西序列、必收敛；极限满足 f(x*) = x*；若有两个不动点，‖x′ − x*‖ ≤ γ‖x′ − x*‖ 只能为 0；误差 ‖x* − xn‖ ≤ γn/(1 − γ) · ‖x1 − x0‖。

关键的一步是定理 3.2：BOE 右端的 f(v) 在最大范数下是收缩映射，‖f(v1) − f(v2)‖∞ ≤ γ‖v1 − v2‖∞，收缩系数正是折扣率 γ。证明（框 3.2）的思路：记 π1*、π2* 分别是对 v1、v2 取 max 的策略，可以把 f(v1) − f(v2) 夹在 γPπ2*(v1 − v2) 和 γPπ1*(v1 − v2) 之间；P 的每行非负且和为 1，所以每个分量都不超过 γ‖v1 − v2‖∞。

左边是一维迭代的“蛛网图”：选一个 f、拖动初值，看收缩映射怎么把任何起点拉到同一个不动点，非收缩时又会怎样。右边在 5×5 网格上，从两个完全不同的初值迭代 BOE，看两条轨迹的距离怎么按 γk 缩小。

从 BOE 解出最优策略

原书 3.4 节 · 第 46–48 页

有了定理 3.2，收缩映射定理直接给出定理 3.3：BOE 的解 v* 总是存在、唯一，可以用 vk+1 = maxπ(rπ + γPπvk) 从任意初值迭代求出，并且指数快速收敛。这个迭代算法有专门的名字：值迭代，第 4 章会细讲。

求出 v* 后，取 π* = argmaxπ(rπ + γPπv*)，代回去得 v* = rπ* + γPπ*v*——所以 v* 就是 π* 的状态值，BOE 是一个特殊的贝尔曼方程，对应的策略是 π*。定理 3.4 说它确实最优：对任意 π 有 v* ≥ vπ。证明只要一行：v* − vπ ≥ γPπ(v* − vπ) ≥ … ≥ γnPπn(v* − vπ) → 0。

定理 3.5：确定性的贪心策略 π*(a|s) = 1（当 a = argmaxa q*(s, a)）就是最优策略。于是四个问题都有了答案：最优策略存在；最优状态值唯一，但最优策略不一定唯一（几个动作的 q* 一样大时任选，或按任意比例混合）；最优策略可以是随机的，但一定存在确定性的最优策略；求法就是值迭代。

易混辨析：贝尔曼方程 vs 贝尔曼最优方程

贝尔曼方程 v = rπ + γPπv：策略给定，线性方程，解出来是这个策略的状态值（策略评估）。贝尔曼最优方程 v = maxπ(rπ + γPπv)：策略也是未知数，非线性，解出来是最优状态值和最优策略。

联系：BOE 是 π = π* 时的贝尔曼方程。两者右端都是收缩映射（收缩系数都是 γ），所以都能从任意初值迭代求解。

易混辨析：最优状态值唯一，最优策略不唯一

v*：BOE 的解，唯一。π*：所有在 v* 下取到 max 的策略都最优；并列时可任选、可混合，所以可以有多个甚至无穷多个，但一定有一个是确定性的贪心策略。

什么会改变最优策略

原书 3.5 节 · 第 49–53 页

看 BOE 的式子，最优策略只由三样东西决定：即时奖励 r、折扣率 γ、模型 p。模型是环境给定的，能调的只有 r 和 γ。原书图 3.4 做了四组对照。基准（γ = 0.9，rforbidden = −1）：从 (4,1) 出发的智能体不怕穿过禁区，因为绕远路的累计回报更低——γ 大，它是远视的。γ = 0.5：不敢冒险了，宁可绕远路避开所有禁区。γ = 0：极度短视，只看即时奖励，大部分格子根本到不了目标。rforbidden = −10：加重惩罚，最优策略就绕开所有禁区。另外所有例子里离目标越近值越大，原因还是折扣：路越长，奖励被折扣得越多。

但改奖励不一定改策略。定理 3.6：把所有奖励做仿射变换 r → αr + β（α > 0），最优状态值变成 v′ = αv* + β/(1 − γ)·𝟙，最优策略不变。原因是所有动作值整体缩放、整体平移，相对大小不变。

一个常见误解由此澄清：为了让智能体“尽快”到达目标，要不要给每一步加一个 −1？不需要。第一，给每步加 −1 是仿射变换（β = −1），最优策略不变。第二，折扣率本身就在惩罚绕路：原书图 3.5 里，s2 直接向下到目标的回报是 1/(1 − γ) = 10，先绕一圈再到目标的回报是 γ2/(1 − γ) = 8.1。路越长，正奖励来得越晚，被折扣得越多。

回扣三问

  1. 为什么选动作值最大的动作能改进策略？最优策略怎么定义？
    先自己答，再点开

    在 vπ 下选 argmax q 得到的新策略满足 rπ′ + γPπ′vπ ≥ vπ，展开可证 vπ′ ≥ vπ（第 4 章引理 4.1）。最优策略是在每个状态上状态值都不小于任何其他策略的策略。

  2. BOE 两个未知数怎么解？收缩映射定理保证什么？
    先自己答，再点开

    先解右端的 max：最优的 π 把概率 1 给 argmaxa q(s, a)，方程化为 v = f(v)。f 是系数为 γ 的收缩映射，所以解存在、唯一、能从任意初值迭代指数收敛（值迭代）；解 v* 是最优状态值，对应的贪心策略最优。

  3. 什么改变最优策略？每步加 −1 有用吗？
    先自己答，再点开

    γ 和奖励的相对大小（模型固定）。γ 小则短视、避险，γ 大则远视、敢冒险；加重禁区惩罚会绕开禁区。每步加 −1 是仿射变换，最优策略不变；而且折扣本身就会惩罚绕路。
