每个节点都向邻居打听，一层一跳

社交网络、引文网络、分子、道路——很多数据天然是“实体—关系”的图：结构不规则、邻居数不固定、节点互相依赖，卷积和循环网络都用不上。图神经网络把“局部交互—状态更新”推广到一般图上：每层每个节点收集邻居的消息、聚合、更新自己。原书的主线是“图表示 → 消息传递 → 具体模型 → 现实约束”：GCN、GraphSAGE、GAT、GIN 都是对“怎么聚合、怎么更新”的不同回答，而过度平滑、过压缩、可扩展性是它们共同的边界。

本系列是教材《神经网络与深度学习（第二版）》（邱锡鹏 著，开放出版前电子稿，本笔记依据 2026 年 7 月 23 日版 PDF）的学习笔记。原书以数学推导为主，这里按“先建直觉、再看公式、最后动手”重新组织：每节先用几段话说清楚它解决什么问题，再给一个可以拖动参数、亲手训练的小实验。公式、定义和例子以原书为准，标注了对应的节号和页码；为演示设的数据和参数会标注“示意”。

图、拉普拉斯矩阵与图信号

原书 9.1 节 · 第 250–254 页

图 𝒢 = (𝒱, ℰ) 由节点和边组成。无向图边是对称关系（好友），有向图边有方向（引用）；同质图只有一类节点和边，异质图有多类（作者、论文、会议；撰写、引用、发表于），需要关系图卷积、异质图注意力等专门建模。原书说欧氏空间（序列、图像）有规则坐标和固定邻域，图是非欧氏结构，邻居关系由边决定。表示方法：邻接矩阵（写公式最方便，稀疏大图很费内存）、邻接表（只存实际的边）、边列表（消息传递实现里常见）。

几个重要的数学量。度：与节点相连的边数（有向图分入度、出度）。同质性：相似节点倾向相连，同质比例 Hratio = 连接同类节点的边数 / 总边数；经典 GCN 默认“邻居信息有帮助”，更适合同质性强的图。与之相对的异配性指不同标签的节点更容易相连——原书特意提醒它和异质图不是一回事（一个说标签是否相似，一个说类型是否不同）。

拉普拉斯矩阵 L = D − A（D 是度矩阵）。给每个节点附一个数，叫图信号 x，则 (Lx)i = Σj Aij(xi − xj)：节点自己与邻居之间的差。二次型 xᵀLx = ½Σ Aij(xi − xj)²：相邻节点越接近，这个值越小——所以 L 衡量图信号的平滑性，这是图正则化、谱聚类、图卷积的数学基础。归一化形式 Lnorm = I − D−1/2AD−1/2 消除了度差异的尺度影响。

图上的三类任务与数据划分

原书 9.2 节 · 第 254–257 页

按预测对象，图学习任务分三层。节点级：节点分类（论文属于哪个领域）、节点回归（道路流量）、节点表示学习。边级：链接预测（两篇论文将来会不会引用；打分可以是 huᵀhv 或 MLP(hu ⊕ hv)）、边分类（正常 / 异常交易）、边回归（拥堵程度）。图级：图分类（分子有没有某种活性）、图回归（溶解度）、图生成（GraphVAE、GraphRNN）。它们共享同一核心：先学节点表示，再按预测对象设计读出——直接取节点表示、组合节点对、或全局汇聚成整图表示。

原书第二版强调了一个容易出错的地方：图上的数据划分。节点和边相互依赖，划分单位必须和预测对象一致。节点任务：传导式设置下模型可以看全图结构和特征，但只在训练节点的标签上算损失；归纳式设置要把新节点或新图从训练计算图里隔离。链接预测：必须把验证、测试正例边从训练图里删掉或遮蔽，否则模型直接“看到”答案；负例采样规则在各集合间保持一致；随时间演化的图要按时间划分。图级任务：以整张图为单位，还要防止近重复样本、同源结构跨集合泄漏。

把这些任务分到三个层级里。

消息传递：聚合、更新、读出

原书 9.3 节 · 第 257–259 页

图神经网络的统一框架是消息传递（MPNN，Gilmer 等 2017）。一层分两步：消息传递与聚合——每个邻居 u 构造一条消息 mu→v = f(hv, hu, he_uv)，再聚合 mv = AGGREGATE({mu→v : u ∈ 𝒩(v)})；节点更新——hv⁽ˡ⁾ = UPDATE(hv⁽ˡ⁻¹⁾, mv)，比如 ReLU(W[hv ⊕ mv])。邻居是一个集合，没有天然顺序，所以聚合函数必须对排列不变：求和、平均、最大值。

一层只能聚合一阶邻居，L 层最多覆盖 L 跳邻域——层数决定了图上的感受野。图级任务还需要全局汇聚（读出）把所有节点表示汇总成整图表示，如 h𝒢 = Σ hv⁽ᴸ⁾。完整流程：初始化 H⁽⁰⁾ 为节点特征 → 逐层消息传递 → 读出 → 任务预测。原书的结论：不同 GNN 的差别，就在“如何聚合邻居、如何更新表示”这两个问题的回答上。

图卷积网络：从谱到局部

原书 9.4.1 节 · 第 259–265 页

GCN（Kipf 和 Welling，2017）想把卷积的两个特征——局部连接、参数共享——推广到图上：节点的一阶邻域就是它的局部感受野，全图共享同一组变换参数。但图上没有规则的平移，卷积怎么定义？原书走了一条“卷积定理 → 傅里叶变换 → 图傅里叶变换 → 谱图卷积 → 局部近似”的路。

关键一步：卷积定理说时域卷积等于频域逐点乘法；而经典傅里叶基 eiωt 正是拉普拉斯算子的特征函数。图虽然没有正弦余弦，但有拉普拉斯矩阵——它的特征向量就是图上的频率基：L = UΛUᵀ，图傅里叶变换 x̂ = Uᵀx，特征值 λ 是“频率”，小 λ 对应相邻节点取值接近的平滑模式，大 λ 对应剧烈振荡的模式。于是谱图卷积 gθ ∗G x = U gθ(Λ) Uᵀx。

它有两个问题：特征分解代价高（O(N²) 甚至更高），滤波器不保证局部。解法是把滤波器写成 L 的多项式 Σ αkLk：Lkx 只依赖 k 跳以内，天然局部。ChebNet 用 Chebyshev 多项式近似、不用特征分解；Kipf 再取 K = 1、λmax ≈ 2、共享参数，加上重规范化技巧（加自环 Ã = A + I），得到 GCN 的一层：H⁽ˡ⁺¹⁾ = σ(D̃−1/2ÃD̃−1/2H⁽ˡ⁾W⁽ˡ⁾)。按节点展开就是 hv = σ(Σu∈𝒩(v)∪{v} W hu/√(d̃ud̃v))：自环保留自身信息、对称归一化平衡度差异、共享变换。

图傅里叶基：归一化拉普拉斯的特征向量

从谱图卷积到 GCN

  1. 卷积定理：f ∗ g = ℱ⁻¹(ℱ{f} ⊙ ℱ{g})——变到频域逐点乘，再变回来。
  2. 图上的频率基：L = UΛUᵀ，特征向量 U 作基，特征值 λ 作频率
    x̂ = Uᵀx，x = Ux̂
  3. 谱图卷积：频域滤波器写成特征值的函数
    g_θ ∗_G x = U g_θ(Λ) Uᵀ x
  4. 问题：特征分解贵、滤波器不局部 → 用 L 的多项式近似，L^k x 只看 k 跳
    g_θ(L) x = Σ_{k=0}^{K} α_k L^k x
  5. ChebNet：Chebyshev 多项式 T_k(L̃)，L̃ = 2L/λ_max − I，复杂度 O(KE)
  6. GCN：K = 1、λ_max ≈ 2、θ = θ′₀ = −θ′₁
    g_θ ∗ x ≈ θ(I + D^{−1/2}AD^{−1/2})x
  7. 重规范化：加自环 Ã = A + I，再推广 θ 为矩阵 W 并加激活
    H⁽ˡ⁺¹⁾ = σ(D̃^{−1/2} Ã D̃^{−1/2} H⁽ˡ⁾ W⁽ˡ⁾)

GraphSAGE 与图注意力网络

原书 9.4.2–9.4.3 节 · 第 265–268 页

GraphSAGE（Graph Sample and Aggregation）的贡献不只是新的聚合方式，更是把邻居采样和归纳学习系统地纳入训练。归纳学习指训练后能推广到没见过的新节点甚至新图；转导学习只对训练时已在图里的节点做预测。每层每个节点只采样最多 S 个邻居，计算规模就不随全图邻居数增长，可以小批量训练。聚合函数有三种：平均、LSTM（LSTM 对顺序敏感，要随机打乱来近似集合输入）、汇聚（max σ(Wpoolhu + b)）；更新 hv = σ(W[hv ⊕ h𝒩S(v)])，常再做 ℓ2 归一化。

GAT（图注意力网络）认为不同邻居的重要性不同，不该像 GCN 那样用只由度决定的固定权重。它在邻域内算注意力：evu = LeakyReLU(aᵀ[Whv ⊕ Whu])，在 𝒩(v) ∪ {v} 上 softmax 得 αvu，再加权聚合 h′v = σ(Σ αvuWhu)。常用多头：中间层拼接、输出层平均。注意 GAT 仍是局部的消息传递，不是 Transformer 那样全节点两两注意。GATv2 调换线性变换和非线性的顺序 evu = aᵀLeakyReLU(W[hv ⊕ hu])，缓解原始 GAT 的“静态注意力”限制。

GIN 与 WL 同构测试：聚合函数决定表达能力

原书 9.4.4–9.4.5 节 · 第 268–271 页

图级任务里，模型能不能区分不同的图结构是关键。两个图只是节点编号、画法不同而连接关系一致，叫同构（存在保持边关系的双射）。判断同构很难，常用 Weisfeiler-Lehman 测试（1-WL，也叫颜色细化）：所有节点初始同色；每一轮把“自身颜色 + 邻居颜色的多重集合”映射成新颜色。某一轮两图的颜色分布不同，就一定不同构；一直相同，也只能说没区分出来，不能断定同构。多重集合关心每个元素出现几次，能区分 {a, a, b} 和 {a, b}。

GIN（图同构网络）的出发点是：如果聚合函数连 1-WL 能区分的邻域多重集合都区分不开，模型的结构表达能力就受限。它用求和聚合 + MLP：hv⁽ˡ⁾ = MLP((1 + ε)hv⁽ˡ⁻¹⁾ + Σu∈𝒩(v) hu⁽ˡ⁻¹⁾)，判别能力可以与 1-WL 相当。平均和最大值会丢掉“有几个”的信息。原书的结论：聚合函数的设计不是实现细节，它直接决定模型能区分哪些结构。

共性问题：过度平滑、过压缩、可扩展性

原书 9.5–9.6 节 · 第 271–274 页

过度平滑：一层消息传递相当于把邻居做一次局部平均或混合，多层堆叠就是反复平均，节点表示越来越像，最后整张图的节点都差不多、分不开。可以用 Dirichlet 能量 E(H) = ½Σ Avu‖hv − hu‖² 测量（就是前面 xᵀLx 的向量版），层数越多它越趋近 0。缓解办法：残差连接保留初始或浅层特征、随机删边（DropEdge）、规范化与正则化（如控制每层的 Dirichlet 能量）。

过压缩：大量远距离信息经过若干层后，被迫通过少数边、低维表示“挤”进某个节点，信息在通道里丢失。它和过度平滑不是一回事：一个是“表示越来越像”，一个是“信息理论上可达，但传播通道太窄”。在长距离依赖、树状扩张、瓶颈结构中尤其明显。缓解：加长程边或重连边、残差 / 跳连 / 全局注意力、更强的读出或记忆。

可扩展性：邻域随层数爆炸、存储需求高、每步访问全图太慢。三条典型路线：邻居采样（GraphSAGE，以节点为中心采样）、子图采样（GraphSAINT，按节点 / 边 / 随机游走采子图）、图划分（Cluster-GCN，先聚类分块再在块上训练），在精度、采样偏差和效率之间权衡。

残差

易混辨析

异质图 vs 异配性：异质图是节点 / 边类型多样；异配性是相连节点的标签倾向不同。一个同质图也可以是异配的。

过度平滑 vs 过压缩：表示趋同 vs 信息被挤压丢失。前者和层数关系密切，后者和图结构的瓶颈关系密切。

归纳 vs 转导：能否推广到训练时没出现的节点或图。

GAT vs 图 Transformer：GAT 只在邻域内注意；图 Transformer 走向全局注意力（原书列为扩展方向）。

1-WL 区分出 vs 没区分出：分出来 ⇒ 一定不同构；没分出来 ⇏ 同构。
