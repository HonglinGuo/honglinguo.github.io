表格装不下时，用一个函数去拟合

前七章的状态值、动作值都存在表格里，一个状态一格。状态一多（或连续），表格就既存不下、也学不动——没访问过的格子永远学不到。这一章把值表示成带参数的函数 v̂(s, w)，于是“更新一个值”变成“更新参数 w”。原书强调理解这个方法的关键是它的三步优化表述：选目标函数、推梯度、用梯度算法求解。神经网络正是在这里进入强化学习的，著名的深度 Q 学习（DQN）也在这一章。

值的表示：从表格到函数

原书 8.1 节 · 第 152–155 页

n 个状态的估计值 v̂(s1), …, v̂(sn) 画在图上就是 n 个点。可以用一条曲线拟合它们，最简单的是直线 v̂(s, w) = as + b = [s, 1][a, b]T = φT(s)w，φ(s) 叫特征向量，w 是参数。换成二次曲线 φ(s) = [s2, s, 1]T，拟合能力更强，参数也更多。只要 v̂ 对 w 是线性的（对 s 可以非线性），就叫线性函数近似，是最简单的情形；不知道选什么特征时，常用神经网络作非线性近似。

与表格相比有两处根本不同。怎么取值：表格直接读一格；函数要把 s 代进去算（神经网络要做一次前向传播）。好处是只存低维的 w，省存储；代价是有近似误差——用低维向量表示高维数据，必然丢信息。怎么更新：表格直接改一格；函数只能通过改 w 间接改值。由此带来另一个好处——泛化：改 w 会同时改变没被访问的状态的值，一个状态的经验能帮到它的邻居。

若已知真值 vπ，找最好的 w 就是最小二乘：min ‖Φw − vπ‖2，解是 w* = (ΦTΦ)−1ΦTvπ。但真值恰恰是不知道的，后面几节就是解决这个问题。

左边：用多项式拟合 25 个状态值（均匀随机策略的真值，按状态编号排开），看阶数和误差。右边：对某一个状态做一次“往上推”的更新，比较表格和函数的反应。

目标函数与平稳分布

原书 8.2.1 节 · 第 156–161 页

目标是让 v̂(s, w) 在所有状态上都逼近 vπ(s)：

J(w) = 𝔼[(vπ(S) − v̂(S, w))2]原书式 (8.3)

S 是随机变量，它的分布是什么？这个问题决定了“哪些状态更重要”。最简单的是均匀分布，所有状态一样重要，J = (1/n)Σ(vπ − v̂)2；但策略可能很少访问某些状态，同等对待并不合理。本章用的是平稳分布 dπ：按策略 π 跑足够久之后，智能体处于各个状态的概率。于是 J(w) = Σsdπ(s)(vπ(s) − v̂(s, w))2，常去的状态权重大。

平稳分布怎么来（原书框 8.1）：[Pπk]ij 是 k 步从 si 到 sj 的概率，dkT = d0TPπk。在一定条件下 Pπk → 𝟙dπT（每行都相同），所以 dk → dπ，与初始分布无关，并满足 dπT = dπTPπ——它是 Pπ 关于特征值 1 的左特征向量。唯一性的条件：马尔可夫过程不可约（任意两状态互相可达）或正则（存在 k 使 Pπk > 0）；ε-贪心这类探索性策略通常就能保证。好消息是：后面的算法不需要算出 dπ，按策略采样，样本自然就服从它。

复现原书图 8.5：2×2 网格上 ε = 0.5 的 ε-贪心策略，理论值 dπ = [0.0345, 0.1084, 0.1330, 0.7241]。从 s1 出发跑 1000 步，看各状态的访问比例怎么收敛。

优化算法：从梯度下降到 TD-Linear

原书 8.2.2–8.2.4 节 · 第 161–167 页

对 J(w) 做梯度下降：∇J = −2𝔼[(vπ(S) − v̂(S, w))∇v̂(S, w)]，所以 wk+1 = wk + α𝔼[(vπ(S) − v̂(S, wk))∇v̂(S, wk)]（常数 2 并进 α）。按 SGD 的思路把期望换成样本：wt+1 = wt + α(vπ(st) − v̂(st, wt))∇v̂(st, wt)。但 vπ(st) 未知，必须再换掉：换成回报 gt 是函数近似的 MC；换成 rt+1 + γv̂(st+1, wt) 是函数近似的 TD：

wt+1 = wt + αt[rt+1 + γv̂(st+1, wt) − v̂(st, wt)]∇wv̂(st, wt)原书式 (8.13)

线性情形 v̂ = φT(s)w，梯度就是 φ(s)，得到 TD-Linear：wt+1 = wt + α[rt+1 + γφT(st+1)wt − φT(st)wt]φ(st)。线性情形理论最清楚，但表达能力有限、特征难选；神经网络像黑箱一样好用。原书坚持讲线性情形还有一个理由：表格法是它的特例——取独热特征 φ(s) = es，v̂(s, w) = w(s)，TD-Linear 就退化成第 7 章的表格 TD（框 8.2）。

原书图 8.7、8.8 在 5×5 网格上用 TD-Linear 评估均匀随机策略：500 个回合、每回合 500 步、随机起点，α = 0.0005，w 按标准正态随机初始化。网格状态是二维位置，用列号 x、行号 y 构造特征：多项式特征（x、y 归一化到 [−1, 1]）[1, x, y] 是平面，[1, x, y, x², y², xy] 是二次曲面，再加三次项共 10 维；傅里叶特征（x、y 归一化到 [0, 1]）cos(π(c1x + c2y))，c1, c2 ∈ {0, …, q}，共 (q + 1)2 维。特征越长，近似越准，但线性近似的误差一般降不到 0。

选一种特征，在浏览器里真的跑 25 万次 TD-Linear 更新，看估计出的值曲面和误差曲线。

TD-Linear 到底在最小化什么

原书 8.2.5 节 · 第 167–179 页

上面的“故事”并不严格：把 vπ 换成 r + γv̂ 之后，算法其实不再最小化 J(w)。原书先分析对应的确定性算法 wt+1 = wt + α𝔼[(r + γφT(s′)w − φT(s)w)φ(s)]（S 服从 dπ），可以化简为 wt+1 = wt + α(b − Awt)，其中

A = ΦTD(I − γPπ)Φ，b = ΦTDrπ，D = diag(dπ)　⇒　w* = A−1b原书引理 8.1、式 (8.21)

A 可逆且正定（框 8.4：证明 D(I − γPπ) 的对称部分严格对角占优），所以收敛到 w* = A−1b；独热特征时 Φ = I，w* = (I − γPπ)−1rπ = vπ，又一次说明表格法是特例。

w* 是什么问题的解？原书比较了三个目标：真值误差 JE = ‖v̂(w) − vπ‖D2（最理想，但要真值）；贝尔曼误差 JBE = ‖v̂(w) − Tπ(v̂(w))‖D2，Tπ(x) = rπ + γPπx 是贝尔曼算子；投影贝尔曼误差 JPBE = ‖v̂(w) − MTπ(v̂(w))‖D2，M = Φ(ΦTDΦ)−1ΦTD 是把向量投影到“所有可表示的近似”上的投影矩阵。TD-Linear 最小化的是投影贝尔曼误差：w* = A−1b 恰好让 JPBE = 0（框 8.5）。它离真值有多远？

‖Φw* − vπ‖D ≤ (1/(1 − γ)) · minw‖v̂(w) − vπ‖D原书式 (8.32)；γ 接近 1 时这个界很松，主要有理论价值

原书还介绍了 LSTD：既然 A = 𝔼[φ(st)(φ(st) − γφ(st+1))T]、b = 𝔼[rt+1φ(st)]，就直接用样本平均估计 Â、b̂，令 w = Â−1b̂。它不需要步长、样本效率高，代价是要存矩阵、求逆。

对每种特征，按模型精确算出 TD 不动点 w* = A−1b、最佳近似 argmin JE，以及误差界；再用 LSTD 从一条采样轨迹估计 w。

易混辨析：真值误差、贝尔曼误差、投影贝尔曼误差

JE = ‖v̂ − vπ‖D²：最直接，但含未知的 vπ。JBE = ‖v̂ − Tπv̂‖D²：要求 v̂ 尽量满足贝尔曼方程，但 Tπv̂ 一般不在可表示空间里，通常降不到 0。JPBE = ‖v̂ − MTπv̂‖D²：先投影再比较，线性情形总能降到 0，TD-Linear 和 LSTD 求的就是它。

动作值的函数近似与深度 Q 学习

原书 8.3–8.4 节 · 第 179–186 页

把 v̂(s, w) 换成 q̂(s, a, w)，就得到函数近似的 Sarsa：w ← w + α[r + γq̂(s′, a′, w) − q̂(s, a, w)]∇q̂(s, a, w)；把 q̂(s′, a′, w) 换成 maxaq̂(s′, a, w)，就是函数近似的 Q-learning。原书图 8.9、8.10 用 5 阶傅里叶特征演示了它们（α = 0.001）。注意这两个算法里策略仍是表格（对 q̂ 取 ε-贪心），还假设状态和动作有限；第 9 章才把策略也换成函数。

深度 Q 学习（DQN）是最早也最成功的深度强化学习算法之一（网络不必很深，网格世界一两层就够）。它最小化贝尔曼最优误差的平方：J = 𝔼[(R + γ maxaq̂(S′, a, w) − q̂(S, A, w))2]。难点在于 w 同时出现在目标 y = R + γ max q̂(S′, a, w) 和 q̂(S, A, w) 里，梯度不好算。于是第一个技巧：目标网络——假设目标里的参数在一段时间内固定为 wT，梯度就简单了；实现上维护主网络 w（每轮都更新）和目标网络 wT（每 C 轮把 w 复制过去）。第二个技巧：经验回放——经验存进回放缓冲区，每次均匀地抽一小批来训练。原书给出的数学理由很有意思：要让目标函数有定义，必须指定 (S, A) 的分布，最简单的假设就是均匀分布；而按行为策略顺序产生的样本彼此相关、也不均匀，均匀抽样正是为了打破相关性、满足这个假设。顺带的好处是每个样本可以被反复使用。

原书图 8.11：均匀随机的行为策略只产生 1000 步，回放缓冲区就是这 1000 个样本，小批量 100；损失收敛到 0，状态值误差也收敛到 0——同样的任务，表格 Q-learning 要 10 万步（图 7.4）。效率来自函数近似的泛化和样本的重复利用。图 8.12：只给 100 步，损失照样收敛到 0，值误差却降不下去——网络把给定的样本拟合得很好，但样本太少，不足以估准最优动作值。

在浏览器里训练一个小 DQN（γ = 0.9，rboundary = rforbidden = −10，rtarget = 1）。选 1000 步或 100 步的经验，看损失和值误差两条曲线的分歧。

算法 8.3　深度 Q 学习（off-policy 版）

  1. 主网络与目标网络取相同初值。把行为策略 πb 产生的经验存入回放缓冲区 ℬ = {(s, a, r, s′)}。每轮：
    1. 从 ℬ 中均匀抽一小批样本
    2. 对每个样本算目标 y_T = r + γ max_a q̂(s′, a, w_T)
    3. 用这批样本更新主网络，最小化 (y_T − q̂(s, a, w))²
    4. 每 C 轮令 wT = w

易混辨析：目标网络 vs 经验回放

目标网络：解决“参数同时出现在目标和预测里、梯度难算且目标会追着自己跑”的问题——把目标里的参数冻结一段时间。经验回放：解决“样本按时间顺序产生、相关且分布不均”的问题——存起来均匀抽样，还能重复使用样本。

表格 Q-learning 能用经验回放吗？能。它是 off-policy，对样本怎么来没有要求，回放只会让样本用得更充分（原书 Q&A）。

易混辨析：损失收敛 vs 学到了

损失（小批量上的 TD 误差平方）收敛到 0，只说明网络把给定样本拟合好了。值误差收敛到 0 才说明最优动作值估准了。样本太少（图 8.12）时前者成立、后者不成立。

回扣三问

  1. 函数代替表格得失如何？为什么用平稳分布加权？
    先自己答，再点开

    得：只存低维参数，省存储；改参数会影响邻近状态，能泛化。失：有近似误差。平稳分布反映策略长期访问各状态的频率，常去的状态更重要；而且按策略采样就自动服从它，不必显式计算。

  2. TD-Linear 怎么来的？真正最小化什么？
    先自己答，再点开

    对 J(w) 做梯度下降 → 用样本代替期望（SGD）→ 把未知的 vπ(st) 换成 r + γv̂(st+1)。换完之后它收敛到 w* = A−1b，最小化的是投影贝尔曼误差（可以降到 0），不是真值误差；与最佳近似的差距有 1/(1 − γ) 的上界。

  3. DQN 为何要两个网络和经验回放？为何均匀采样？
    先自己答，再点开

    参数同时出现在目标和预测中，固定目标网络才能简单地求梯度。目标函数要求 (S, A) 有确定的分布，最简单的假设是均匀分布；顺序产生的样本相关且不均匀，从回放缓冲区均匀抽样正是为了满足这个假设，同时还能重复利用样本。
