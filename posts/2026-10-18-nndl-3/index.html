同一条直线，四种学法

第 3 章的四个模型——Logistic 回归、Softmax 回归、感知器、支持向量机——用的都是同一个线性打分 wᵀx + b，决策边界都是超平面。它们的差别只在一处：用什么损失函数、按什么准则去找这条线。概率建模、错误驱动、间隔最大化，三种思路分别对应交叉熵、感知器损失和 Hinge 损失。这一篇在同一批二维数据上把它们都训练一遍，最后把损失函数画在一张图上比较。

本系列是教材《神经网络与深度学习（第二版）》（邱锡鹏 著，开放出版前电子稿，本笔记依据 2026 年 7 月 23 日版 PDF）的学习笔记。原书以数学推导为主，这里按“先建直觉、再看公式、最后动手”重新组织：每节先用几段话说清楚它解决什么问题，再给一个可以拖动参数、亲手训练的小实验。公式、定义和例子以原书为准，标注了对应的节号和页码；为演示设的数据和参数会标注“示意”。

本篇要回答的 3 个问题

  1. “线性分类器”的“线性”指什么？Logistic 回归输出了一个非线性的概率，为什么还叫线性模型？
  2. 感知器和支持向量机都能把线性可分的数据分开，它们找到的直线有什么不同？
  3. Logistic、感知器、Hinge、平方损失放在一起比，各自在“分对了但不够自信”和“分错了”时怎么罚？

线性判别函数与决策边界

原书 3.1.1 节 · 第 60–63 页

线性模型 f(x; w) = wᵀx + b 的值域是实数，做分类还需要一个非线性的决策函数 g(·)：y = g(f(x; w))，这时 f 叫判别函数。二分类最简单的 g 是符号函数 sgn。所谓“线性分类模型”，指的是决策边界是线性超平面——而不是说整个模型没有非线性。

所有满足 f(x; w) = 0 的点构成决策边界（D 维空间里是 D − 1 维的超平面），它把空间一分为二，并且与权重向量 w 正交。一个点到边界的有向距离是 γ = f(x; w)/‖w‖，也可以看成 x 在 w 方向上的投影。学习的目标是让每个样本都满足 y⁽ⁿ⁾f(x⁽ⁿ⁾; w) > 0；存在这样的 w，就说训练集线性可分。

最直接的损失是 0-1 损失 I(yf < 0)，但它几乎处处梯度为 0、在边界处不可导，没法用梯度方法优化。所以实际都用连续、凸的替代损失（交叉熵、Hinge 等），它们通常是 0-1 损失的连续上界——这就是本章四个模型分化的起点。

拖动 w 和 b，看边界怎么转、怎么平移；点画布任意位置看那一点的有向距离。默认值是原书习题 3-3 的 w = [2, −1]ᵀ、b = 1。

多分类：一对其余、一对一、argmax

原书 3.1.2 节 · 第 63–64 页

类别数 C > 2 时需要多个判别函数，原书介绍三种组织方式。一对其余：C 个二分类器，第 c 个把类别 c 和其余所有类分开。一对一：C(C − 1)/2 个二分类器，每个只分开一对类别，最后投票。argmax：也是 C 个判别函数 fc = wcᵀx + bc，但不再各自判断正负，而是取得分最高的那一类。

前两种本质上都是把多分类拆成多个二分类，问题是特征空间里会出现谁都不认领、或者好几个都认领的区域（原书图 3.3 的“?”）。argmax 方式给每个点都恰好一个答案，相邻两类 i、j 的边界由 fi − fj = 0 决定，法向量是 wi − wj。原书的结论：数据集多类线性可分，就一定存在一个 argmax 方式的线性分类器把它分开。后面的 Softmax 回归用的就是 argmax。

Logistic 回归：把打分变成概率

原书 3.2 节 · 第 65–67 页

Logistic 回归用激活函数 σ 把线性打分“挤压”到 (0, 1)：p(y = 1|x) = σ(wᵀx) = 1/(1 + exp(−wᵀx))（这里 y ∈ {0, 1}，x、w 是增广向量）。虽然输出是非线性的概率，但决策边界仍是 wᵀx = 0，所以它仍然是线性分类模型。统计里把 g 的逆函数叫联系函数。

把式子反解：wᵀx = log [p(y=1|x) / p(y=0|x)]。右边概率之比叫几率（odds），取对数叫对数几率（logit）。所以 Logistic 回归就是“用线性回归去拟合对数几率”，也叫对数几率回归。打分每增加 1，几率乘以 e ≈ 2.72。

训练用交叉熵损失。借助 σ′(z) = σ(z)(1 − σ(z))，梯度化简成一个非常干净的形式：∂ℛ/∂w = −(1/N) Σ x⁽ⁿ⁾(y⁽ⁿ⁾ − ŷ⁽ⁿ⁾)——预测值和真实值之差乘以输入。风险函数是连续可微的凸函数，所以梯度下降能找到全局最优，也可以用牛顿法这类高阶方法。原书特别提示：这个“误差 × 输入”的梯度形式，和后面多层神经网络输出层的处理完全一致。

Softmax 回归：多类的 Logistic

原书 3.3 节 · 第 67–72 页

Softmax 函数把任意实数向量 z 映射成概率分布：softmax(z)c = exp(zc)/Σ exp(zc′)。指数放大了分量之间的差异，最大分量的概率最大；实际计算时先减去 max z 防止溢出；C = 2 时退化为 Logistic 函数。

Softmax 回归（多项 / 多类 Logistic 回归）预测 ŷ = softmax(Wᵀx)，决策取 argmax wcᵀx——正是上一节的 argmax 方式。C = 2 时决策变成 I((w₁ − w₀)ᵀx > 0)，对应二分类里的 w = w₁ − w₀。用交叉熵训练，梯度和 Logistic 回归同一个形状：∂ℛ/∂W = −(1/N) Σ x⁽ⁿ⁾(y⁽ⁿ⁾ − ŷ⁽ⁿ⁾)ᵀ，y 是 one-hot 向量。

原书点出一个容易忽略的性质：参数冗余。所有 wc 同时减去同一个向量 v，输出概率一点不变——真正起作用的是类别之间的打分差，不是各自的绝对位置。所以 Softmax 回归通常要加正则化约束参数，这个性质也正是“减去最大值防溢出”的依据。

感知器：错了才改

原书 3.4 节 · 第 72–79 页

感知器由 Rosenblatt 于 1957 年提出，是只有一个神经元的最简单神经网络——最早还是一台机器，后来才变成 IBM 704 上的程序。它的学习规则是错误驱动的在线学习：w 从 0 开始，每遇到一个分错（或正好在边界上，ywᵀx ≤ 0）的样本，就 w ← w + yx。这等价于对损失 max(0, −ywᵀx) 做随机（次）梯度下降。

收敛性（Novikoff，1963）：如果训练集线性可分，存在单位向量 w* 使所有样本 w*ᵀ(yx) ≥ γ，令 R 为最大样本模长，那么权重更新次数不超过 R²/γ²。证明很漂亮：‖wK‖² 的上界随 K 线性增长（KR²），下界随 K 平方增长（K²γ²），两者一夹，K ≤ R²/γ²。间隔越大，收敛越快。

感知器的三个不足：能分开但不保证泛化能力；对样本顺序敏感，顺序不同找到的超平面也不同；线性不可分时不保证收敛。改进之一是投票感知器：保存所有 K 个权重，每个按“存活了多少步”加权投票；它的简化版平均感知器直接用所有步权重的平均 w̄。感知器还能通过联合特征 φ(x, y) 推广到多分类和结构化学习（广义感知器）。

支持向量机：离两边都尽量远

原书 3.5.1、3.5.3 节 · 第 79–83 页

线性可分的数据，能分开它的直线有无数条，感知器随便找到一条就停了。支持向量机要找的是最“稳”的那条：定义间隔 γ 为所有样本到超平面的最短距离，目标是让 γ 最大。间隔越大，划分越不容易受噪声影响。由于同时缩放 w 和 b 不改变距离，可以规定 ‖w‖·γ = 1，问题变成 min ½‖w‖²，s.t. y⁽ⁿ⁾(wᵀx⁽ⁿ⁾ + b) ≥ 1。线性可分时间隔最大的超平面是唯一的。

用拉格朗日乘数法转到对偶问题，得到 w = Σ λny⁽ⁿ⁾x⁽ⁿ⁾。KKT 互补松弛条件告诉我们：不在约束边界上的样本 λn = 0；只有正好落在 y(wᵀx + b) = 1 上的样本 λn > 0，它们叫支持向量。决策函数只依赖支持向量，删掉其他样本，结果不变。实际求解常用 SMO 算法。

数据不可分时，引入松弛变量 ξn 允许部分样本违反约束，目标变成 ½‖w‖² + CΣξn，叫软间隔。把最优的 ξ 代回去，就得到 Σ max(0, 1 − y(wᵀx + b)) + (1/2C)‖w‖²——Hinge 损失加 ℓ2 正则。C 越大越不容忍违规，间隔越窄。

核函数：换个空间就线性可分了

原书 3.5.2 节 · 第 82–83 页

SVM 的对偶形式里，样本只以内积 x⁽ᵐ⁾ᵀx⁽ⁿ⁾ 的形式出现。把内积换成核函数 k(x, z) = φ(x)ᵀφ(z)，就等于先把样本映射到更高维的特征空间 φ 再做线性分类，决策函数变成 sgn(Σ λny⁽ⁿ⁾k(x⁽ⁿ⁾, x) + b)。在特征空间里是超平面，回到原始空间就是曲线。

妙处在于不必写出 φ。原书的例子：k(x, z) = (1 + xᵀz)² 恰好等于 φ(x)ᵀφ(z)，其中 φ(x) = [1, √2x₁, √2x₂, √2x₁x₂, x₁², x₂²]ᵀ——算一次二维内积，就等于在六维空间里算内积，这叫核技巧。高斯核 k(x, z) = exp(−γ‖x − z‖²) 对应的 φ 甚至是无穷维的。

损失函数对比

原书 3.6–3.7 节 · 第 83–86 页

统一用 y ∈ {+1, −1}、f = wᵀx + b，所有损失都能写成 yf（可以叫“带符号的打分”）的函数：yf > 0 分对，越大越有把握；yf < 0 分错，越小错得越离谱。好的分类损失应该随 yf 增大而减小。

Logistic 回归的交叉熵改写后是 log(1 + exp(−yf))：平滑、有概率解释，分对了也还有一点点损失。感知器损失 max(0, −yf)：只关心是否分错，分对就是 0。Hinge 损失 max(0, 1 − yf)：不仅要分对，还要留出间隔，0 < yf < 1 也会被罚。平方损失 (y − f)² 可以写成 (1 − yf)²——问题在于 yf > 1（分得非常对）时它反而会上升，惩罚“太正确”，所以不适合分类。

易混辨析

判别函数 vs 决策函数：判别函数是线性打分 f = wᵀx + b；决策函数 g 把打分变成类别（sgn、argmax）或概率（σ、softmax）。

激活函数 vs 联系函数：Logistic 回归里 σ 叫激活函数，它的逆函数（logit）在统计文献里叫联系函数。

投票感知器 vs 平均感知器：前者保存全部 K 个权重、加权投票；后者只保存平均权重 w̄，用一次内积预测，是前者的近似简化。

硬间隔 vs 软间隔：硬间隔要求所有样本 y(wᵀx + b) ≥ 1，只适用于线性可分；软间隔允许违规但按 C 罚，等价于 Hinge 损失 + ℓ2 正则。
