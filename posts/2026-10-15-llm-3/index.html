神经网络：会弯折的加法

按词频查表的老办法，遇到没见过的前文就束手无策；手写规则又永远写不完。我们需要一台能从数据里自己学出规律的机器。神经网络的零件简单得出奇：乘、加，再折一下。

一个神经元，像一个可调的开关

wx + b，再 ReLU

前两篇说清了目标：让模型的概率表尽量接近人，用交叉熵打分。那这台预测机器用什么来做？让人写规则写不完，按前文查统计表又会遇到组合爆炸：前文一长，绝大多数组合从没出现过，查表只能得到“没见过”。我们需要一个能从数据里学出规律、举一反三的工具，这就是神经网络。

它的基本单元叫神经元，只做两件事：先把输入乘上权重、加上偏置，再把结果“弯折”一下，最常用的是 ReLU，负数变成 0，正数原样输出。于是一个神经元就像一个可调的开关：偏置决定它在哪里打开，权重决定打开后涨得多快、朝哪个方向。

不折一下，叠多少层都是一条直线

非线性

很多神经元并排就是一层，一层的输出作为下一层的输入，一层层叠起来就是网络。网络里所有权重和偏置统称参数，它们决定了这个网络算的是什么函数，训练就是去调它们。

为什么每层都要弯折一下？因为直线套直线还是直线：先算 2x+1 再算 3 倍减 2，结果是 6x+1，叠多少层都等价于一层，只能表示最简单的直线关系。加上 ReLU 这样的非线性，每个神经元贡献一个拐点，网络才能拼出弯弯曲曲的复杂形状。

最后一层：把分数变成概率

Softmax

网络算出来的只是一堆数字，而语言模型要的是下一个 token 的概率。做法是：最后一层给词表里每个 token 配一个神经元，算出一个分数（常叫 logits），这一层不再弯折，否则负分全变成 0 就分不出高低了。

但分数不能直接当概率：它可正可负，加起来也不等于 1。Softmax 负责转换：先对每个分数取指数，保证都是正数、而且高分被放大；再除以总和，保证加起来正好是 1。每个候选的概率都大于 0，所以模型猜错时交叉熵也不会变成无穷大。

到这里语言模型的骨架就齐了：前文 → 多层神经网络 → 每个 token 的分数 → Softmax → 下一个 token 的概率。

拖动四个候选的分数看概率变化，再试试“所有分数都加 3”。

“这个周六，我们去____吧”

  • 只有分数之间的差距才重要：全体加同一个数，概率纹丝不动。
  • 再低的分数，概率也大于 0。这样模型猜错时也不会“完全没想到”，第 2 篇里的交叉熵才不会变成无穷大。

神经元够多，什么曲线都能拼出来

通用逼近

这样一层层叠起来的网络，能力上限在哪里？答案出奇地好：通用逼近定理说，只要神经元足够多，哪怕只有一个隐藏层，也能以任意精度逼近任意连续函数。“输入前文、输出下一个 token 的概率”也是一个函数，只是输入输出都有成千上万维，所以神经网络原则上有能力表示它。

用 ReLU 很容易看出为什么：三个 ReLU 一加一减能拼出一顶“小帐篷”，两边是 0、中间一个尖；许多帐篷并排摆好、各自调高矮，加起来就是一条贴着目标曲线的折线。

但这个定理没说要多少神经元，没说参数怎么找到，也没说能否推广到没见过的数据。

同样的零件，叠深比铺宽划算得多

深度

既然一层就够，为什么 GPT-3 有 96 层？原因之一是：同样多的神经元，叠深能表示的函数复杂得多。两个神经元能把 0 到 1 这段线对折一次，把输出再送进同样的两个神经元就是再折一次，每多一层，折线段数就翻倍；而单层网络里每个神经元只能贡献一个拐点。

另一个原因是复杂规律本来就是一层层搭起来的：字组成词，词组成短语，短语组成句子的意思。研究者在真实模型里也看到，较低的层多捕捉拼写、搭配这类表层模式，较高的层多捕捉语义。

代价是越深越难训练，这要等下一篇讲完训练再解决。
