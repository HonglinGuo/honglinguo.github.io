每个 token 换成一串数

嵌入向量

前四篇备齐了零件，现在看它们拼成的结构：2017 年 Google 提出的 Transformer，如今几乎所有大语言模型都基于它。数据在里面这样流动：token 编号 → 嵌入成向量 → 加入位置信息 → 若干层“注意力 + 前馈网络” → 输出每个 token 的分数 → Softmax。

第一步是把编号变成有意义的数。编号本身没有含义，452 并不比 25“大”，所以每个 token 会查表换成一串几千维的数，叫嵌入向量。每一维代表什么不是人定的，这些数也是参数，一起训练出来。训练会让常出现在相似上下文里的词，比如“茶”和“咖啡”，被推到相近的方向。于是模型在一句话里学到的东西，能自然迁移到没见过的近义说法上，这正好解决了查表法“没见过就不会”的难题。

几千维，为什么装得下几十万个概念

叠加

语言里的概念有几十万个，向量却只有几千维，装得下吗？如果每个概念都要占一个和其他概念严格垂直的方向，4096 维最多只能放 4096 个。

但只要允许一点误差，情况就完全不同。高维空间有一个反直觉的性质：随手取两个方向，几乎总是接近垂直。三维空间里，两个随机方向的夹角落在 88° 到 92° 之间的概率只有约 3.5%；到 GPT-3 的 12288 维，这个概率超过 99.98%。“几乎垂直”的方向能放下的数量随维度指数增长，于是模型可以把远多于维度数的概念各放一个几乎互不干扰的方向，这叫叠加。代价是读一个概念时会混进一点别的噪声，好在一段话里同时用到的概念很少。

随机两方向夹角密度 ∝ sind−2θ
维度越高越集中在 90° 附近。

高维空间“很宽敞”。

概念对应的是方向，而且彼此叠加。

注意力：拿着问题，去前文里找答案

Q · K · V

嵌入表给每个 token 的向量是固定的，不看上下文：“苹果”在“吃苹果”和“苹果手机”里拿到的是同一个向量。可理解一句话离不开上下文，代词“它”指谁、“一杯”后面该接什么，往往取决于好几个 token 之前的词。

最简单的办法是把前文所有向量平均一下，但有用的信息会被无关的词冲淡。真正需要的是有选择地收集，这就是注意力：每个位置算出一个查询（我在找什么），每个位置还有一个键（我这里有什么）和一个值（被关注时交出什么）。查询和每个键做点积打分，Softmax 变成权重，再按权重把值加起来，结果加回当前位置的向量。经过注意力之后，每个位置的向量里就融进了上下文。

下面点任意一个词设为当前位置，切换两个“头”，看它把注意力分给了谁、收集到了什么。

点任意一个词，把它设为“当前位置”（橙框）。每个词下方的蓝条就是当前位置分给它的注意力权重。键是二维的教学构造：第 1 维表示“是会动的东西”，第 2 维表示“是物件或地点”。

同一句话里同时存在好几种关系，所以真实模型会并行跑几十组独立的查询、键、值，每组叫一个“头”，最后把所有头的结果拼起来。谁该关注谁不是人规定的，而是训练中为了降低交叉熵自己长出来的。

概念

注意力
每个位置按相关程度给前文各位置分配权重，再把它们的信息加权平均收集过来。
查询 Q
当前位置“想找什么”。

归纳头

只许往前看

因果掩码

生成文字的时候，模型只知道已经写出的部分。训练时也必须保持一致：每个位置只能看它自己和前面的位置，否则就是偷看答案。做法是把“未来位置”的注意力分数设为负无穷，经过 Softmax 后权重就是 0，这叫因果掩码。

它还带来一个大好处：一段文本只需要算一遍，每个位置都同时在做自己那道“猜下一个”的题，彼此互不偷看。一段 1000 个 token 的文本，一次就提供约 1000 道练习题，这是 Transformer 训练效率高的重要原因，也是语言模型只需要原始 Transformer 中“解码器”那一半的原因。

点左边任意一行，看这个位置能看到哪些词、要预测的是什么。

注意力本身不分先后

旋转位置编码 RoPE

注意力只看向量像不像，本身并不知道顺序：把两个词互换位置，打分结果完全不变。可“狗咬人”和“人咬狗”用字相同，意思相反，所以必须额外告诉模型位置信息。

原始 Transformer 给每个位置生成一个特定的向量，加到 token 的向量上。许多新模型则用旋转位置编码（RoPE）：不改 token 向量本身，而是在算注意力时，把查询和键按“与位置成正比的角度”各转一下。两个向量的点积只取决于它们的长度和夹角，各自转过之后，多出来的夹角只和两者相隔多远有关。于是注意力分数只看相对距离，不看绝对位置，这通常更有用：紧挨着的词往往比 500 个 token 之前的词更相关，不管这句话出现在文章哪里。

概念

位置编码
让模型知道 token 顺序的信息；注意力本身对顺序不敏感。

原始 Transformer 的做法：把按位置算出的正弦、余弦向量加到 token 向量上。

两个 token 相隔多远，比它们的绝对位置更有用。

q 转 mθ，k 转 nθ，点积只取决于 (n − m)θ
RoPE 让分数只依赖相对距离。
向量拆成许多二维对，各对转速不同
快的对近距离敏感，慢的能感知远处。
Llama 等许多模型使用 RoPE

1750 亿个参数，都在哪

Transformer 块

注意力负责让各个位置交换信息，之后每个位置还要各自经过一个前馈网络，也就是第 3 篇讲的“加权求和 + 弯折”：先把向量放宽到约 4 倍，经过非线性，再压回原来的宽度。注意力主要在做加权平均，真正做复杂变换的主要是前馈网络。有研究认为它像一张“键-值记忆”：识别出“某国的首都是”这样的模式，就提高对应城市的分数，不过知识分散在大量参数里，指不出哪个参数存着哪条事实。

一个 Transformer 块就是注意力加前馈网络，每个子层前做归一化、外面套残差连接，再把这样的块堆几十层。层数越往后，每个位置融合的上下文越多，最后一个位置的向量就代表了“读完整段之后接下来该说什么”。
