没有模型，就用平均代替期望

前四章的算法都要知道 p(s′|s, a) 和 p(r|s, a)。原书在这里讲了一句很朴素的话：没有模型就得有数据，没有数据就得有模型，两样都没有就什么也做不了。“数据”指智能体与环境交互得到的经验样本。动作值本来就是回报的期望，期望可以用样本平均来估——把策略迭代里依赖模型的那一步换成平均，就得到第一个无模型算法。这一章由简到繁走三步：MC Basic、MC Exploring Starts、MC ε-Greedy，最后落到探索与利用的权衡。

本系列是教材《强化学习的数学原理（Mathematical Foundations of Reinforcement Learning）》（赵世钰（Shiyu Zhao）著，西湖大学；Springer Nature 与清华大学出版社 2025 年出版，作者在 GitHub 免费公开全书 PDF 与课件，本笔记依据仓库中 2025 年 7 月更新的英文 PDF（已含勘误））的学习笔记。原书仓库没有附带开源许可证，版权归作者与出版社所有；这里不转载原文和插图，而是按“先说清楚它解决什么问题、再动手算、最后记下来”的顺序用自己的话重讲，网格世界、算法与图都在浏览器里重新实现和手绘。公式、定义、例子与参数以原书为准，标注了对应的节号和页码；页面里的模拟结果标注“示意”，复现出原书图中数值的地方标注“原书数据”。

动机：均值估计

原书 5.1 节 · 第 78–80 页

为什么从“估计一个随机变量的均值”讲起？因为状态值和动作值的定义都是回报的期望，估计它们本质上就是均值估计。求 𝔼[X] 有两条路：有模型——知道分布 p(x)，直接算 Σp(x)x；无模型——不知道分布，但有样本 x1, …, xn，用 x̄ = (1/n)Σxj 近似。用随机样本解估计问题的一大类技术，统称蒙特卡罗（MC）方法。

样本平均为什么可信？大数定律：对独立同分布（i.i.d.）的样本，𝔼[x̄] = 𝔼[X]（无偏），var[x̄] = var[X]/n（方差随 n 趋于 0）。原书强调 i.i.d. 这个前提：如果样本相关，比如极端情况下所有样本都等于第一个，那么平均永远等于第一个样本，用多少样本都没用。

抛硬币（正面 +1、反面 −1，真实均值 0）：看样本平均怎么收敛；再切换到“相关样本”，看大数定律如何失效。

MC Basic：把策略迭代变成无模型

原书 5.2 节 · 第 80–86 页

回看策略迭代：策略改进 πk+1(s) = argmaxa qπk(s, a)，核心是动作值——策略评估算状态值只是为了再用模型算出动作值。动作值有两种求法：有模型的 qπk(s, a) = Σp(r|s, a)r + γΣp(s′|s, a)vπk(s′)；无模型的——从 (s, a) 出发按 πk 跑 n 个回合，用回报的平均估计：

qπk(s, a) = 𝔼[Gt|St = s, At = a] ≈ (1/n) Σi gπk(i)(s, a)原书式 (5.2)

用它替换策略评估，就是 MC Basic。注意它直接估计动作值：如果只估计状态值，改进策略时还得用模型把状态值换成动作值，就又不是无模型了。样本足够时 MC Basic 收敛（因为策略迭代收敛）；实际中样本不够，估计不准，但它往往仍能工作，道理和截断策略迭代一样。原书坦言它样本效率太低、不实用，讲它是为了把核心思想和后面的复杂技巧分开。

原书用 5×5 网格（rforbidden = −10）展示了一个重要现象：回合长度决定能学到什么。回合长度为 1 时，只有目标旁边的格子有非零值——别的格子一步之内拿不到正奖励；长度增加，非零值从目标向外扩散。从左下角绕开禁区到目标至少要 15 步，所以长度必须 ≥ 15。但也不必无限长：长度 30 时策略已经最优，值还没到最优。这关联到稀疏奖励问题：不到目标就没有正奖励，状态空间一大，回合很难长到能碰到目标。一个简单对策是设计非稀疏奖励，例如在目标附近给小的正奖励，形成“吸引场”。

拖动回合长度，重新运行 MC Basic 直到策略不再变化。网格世界和策略都是确定性的，所以每个 (s, a) 只需一个回合。

算法 5.1　MC Basic策略迭代的无模型版本

  1. 初始策略 π0。第 k 轮，对每个状态 s、每个动作 a：
    1. 从 (s, a) 出发、按 πk 收集足够多的回合
    2. 策略评估：qk(s, a) = 这些回合回报的平均
  2. 策略改进：对每个 s，πk+1(a|s) = 1 当 a = argmaxa qk(s, a)

更高效地用样本：MC Exploring Starts

原书 5.3 节 · 第 86–89 页

MC Basic 浪费在两处。第一，样本用得少：一个回合 s1 —a2→ s2 —a4→ s1 —a2→ s2 —a3→ s5 —a1→ … 只用来估计起点 (s1, a2) 的值，这叫初次访问（initial-visit）。其实每访问一次某个 (s, a)，后面那一截轨迹就是从它出发的一个子回合，也能用来估计它。只用每个 (s, a) 第一次出现的那截叫首次访问（first-visit），出现几次用几次叫每次访问（every-visit）。每次访问最省样本，但同一回合里同一对的两次样本是相关的（第二截是第一截的子集），离得远时相关性不强。

第二，策略更新得慢：MC Basic 要等所有回合收集完才改一次策略。改成每收到一个回合就用它的回报更新估计、立刻改进策略——单个回合的回报当然不准，但这正是第 4 章广义策略迭代的精神：值不必评估准，策略就可以改。

两点合起来就是 MC Exploring Starts。实现上，计算每一步回报时从回合末尾倒着走：g ← γg + rt+1，一遍扫完就得到所有步的回报。它仍然需要探索性起点条件：每个 (s, a) 都要有足够多的回合从它出发，否则没被充分探索的动作值估不准，可能恰好错过最优动作。这在需要与物理环境交互的应用里很难满足。

随机生成一个短回合，看倒序计算回报的过程；切换三种访问策略，数一数这个回合给多少个 (s, a) 提供了样本。

算法 5.2　MC Exploring Starts每次访问 + 逐回合改进

  1. 对所有 (s, a) 初始化 q(s, a)、Returns(s, a) = 0、Num(s, a) = 0。对每个回合：
    1. 选起点 (s0, a0)，保证每一对都可能被选到（探索性起点），按当前策略生成长度 T 的回合
    2. g ← 0；对 t = T−1, T−2, …, 0：g ← γg + r_{t+1}，Returns(st, at) += g，Num(st, at) += 1，q(st, at) = Returns/Num，π(·|st) 改为对 q(st, ·) 的贪心

易混辨析：初次访问、首次访问、每次访问

初次访问（initial-visit）：一个回合只用于估计它的起点 (s0, a0)，MC Basic 用的就是它。首次访问（first-visit）：每个 (s, a) 只用它在回合里第一次出现之后的那截。每次访问（every-visit）：出现几次就用几次，样本最多，但同一回合内的样本相关。

MC ε-Greedy：不需要探索性起点

原书 5.4 节 · 第 89–92 页

探索性起点要求“每个 (s, a) 都被访问足够多次”。另一个办法是让策略本身就会探索：在每个状态对每个动作都有正概率的策略叫软策略。用软策略，一个足够长的回合就能把所有 (s, a) 访问很多遍，不必从每一对单独出发。最常用的软策略是 ε-贪心：

π(a|s) = 1 − ε(|𝒜(s)| − 1)/|𝒜(s)|（贪心动作），ε/|𝒜(s)|（其余 |𝒜(s)| − 1 个动作）ε ∈ [0, 1]

ε = 0 就是贪心；ε = 1 就是均匀随机。贪心动作的概率 1 − ε + ε/|𝒜| 总不小于其他动作。采样时可以这样做：取均匀随机数 x，x ≥ ε 选贪心动作，否则在全部动作里均匀选一个（可能又选到贪心动作）。

把策略改进从“在所有策略里找最优”改成“在所有 ε-贪心策略 Πε 里找最优”，解就是对 argmax q 取 ε-贪心——这就是 MC ε-Greedy（算法 5.3，同样用每次访问）。代价是：它收敛到 Πε 里的最优策略，但未必是所有策略里的最优；ε 足够小时两者接近。原书图 5.5 演示了极端情形：每轮只用一条一百万步的回合，从均匀策略出发，ε = 0.5，两轮就得到最优的 ε-贪心策略。

在基准网格上照做（这里每轮用一条一百万步的回合）：点“下一轮”，看策略怎么从均匀随机变成 ε-贪心。

ε-贪心的探索与利用

原书 5.5 节 · 第 92–97 页

探索是尽可能尝试各种动作，让每个动作都被访问、被评估好；利用是选当前估计中值最大的动作。由于估计本身因探索不足而不准，必须边利用边探索，才不会错过最优动作。ε-贪心的思路是：牺牲一点最优性（利用），换取探索能力。

最优性随 ε 变差。原书图 5.6 取一组“一致”的 ε-贪心策略（概率最大的动作都和最优贪心策略相同），ε 从 0 增到 0.5，状态值一路下降；ε = 0.5 时连目标格的值都变成最小之一——在目标原地不动时，有很大概率被随机动作带进周围的禁区。图 5.7 进一步求出 Πε 里的最优策略：ε = 0.1 时与最优贪心策略一致，ε 增到 0.2 就不一致了，目标格的最优动作从“原地不动”变成“逃离”——因为待着反而更容易被随机动作推进禁区。

探索能力随 ε 增强。ε = 1（均匀随机）时，一条一百万步的回合对 125 个 (s, a) 的访问次数几乎均匀；ε = 0.5 时，有的动作被访问超过 25 万次，大多数只有几百甚至几十次。实用的做法是先大后小：开始时 ε 大，加强探索；逐渐减小，保证最终策略的最优性。

拖动 ε：左边是按模型精确求出的 Πε 内最优策略及其状态值（rforbidden = −10），右边是两条一百万步回合的访问次数分布。

易混辨析：探索 vs 利用

探索：尝试尽可能多的动作，让估计变准，ε 大则强。利用：选当前估计最好的动作，与最优性直接相关，ε 小则强。ε-贪心用一个参数在两者间折中，常见做法是让 ε 随训练逐渐减小。

Πε 内最优 vs 全局最优：MC ε-Greedy 收敛到的是 ε-贪心策略集合内的最优；ε 大时它可能与全局最优策略“不一致”（如目标格选择逃离）。

回扣三问

  1. 为什么估计动作值是均值估计？MC Basic 和策略迭代差在哪？
    先自己答，再点开

    动作值的定义就是回报的期望，可以用样本回报的平均估计（大数定律）。MC Basic 只把策略迭代的策略评估从“用模型解贝尔曼方程”换成“用回报平均直接估计动作值”，策略改进不变。

  2. 为什么回合要够长？三种访问策略的区别？
    先自己答，再点开

    回合短于到达目标所需的最少步数时，回报恒为 0（稀疏奖励），值估计不出来；5×5 例子中至少要 15 步。初次访问只估计起点；首次访问每对只用第一次出现之后的那截；每次访问出现几次用几次，最省样本但样本相关。

  3. ε-贪心怎么去掉探索性起点？ε 取多大？
    先自己答，再点开

    ε-贪心是软策略，每个动作都有正概率，一条足够长的回合就能访问所有 (s, a)。ε 大探索强、最优性差，ε 小反之；常用先大后小。收敛结果只在 ε-贪心策略集合内最优。
