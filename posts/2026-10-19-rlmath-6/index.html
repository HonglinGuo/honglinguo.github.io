每来一个样本，就往前挪一小步

第 5 章的蒙特卡罗要等整个回合结束、把回报收集齐才能更新，是非增量的；第 7 章的时序差分则每来一个样本就更新一次，是增量的。两者之间有一道知识鸿沟，原书专门用这一章来填：随机近似理论。这一章一个强化学习算法都没有，但读完它，再看 TD 和 Q-learning 就不会觉得突兀——它们本质上都是在用带噪声的样本求解贝尔曼方程的根。

动机：增量式的均值估计

原书 6.1 节 · 第 102–103 页

估计 𝔼[X] 有两种算平均的方式。非增量：把样本全收集完再求平均——样本多时要等很久。增量：记 wk+1 = (1/k)Σi≤kxi，简单推导可得

wk+1 = wk − (1/k)(wk − xk)原书式 (6.2)

每来一个样本就能立刻得到当前平均。开始时样本少、不准，但“聊胜于无”，随着样本增多由大数定律逐渐变准。再把系数 1/k 换成一般的 αk > 0：

wk+1 = wk − αk(wk − xk)原书式 (6.4)：本章与第 7 章最常见的形式

这时 wk 不再有显式表达式，它还收敛到 𝔼[X] 吗？下一节的 RM 定理会告诉我们：只要 αk 满足一些温和的条件就收敛。第 7 章的 TD 算法正是这个形式，只是更复杂。

Robbins-Monro 算法

原书 6.2 节 · 第 103–109 页

随机近似泛指求根或优化问题的一大类随机迭代算法。它的长处是不需要目标函数或导数的表达式。Robbins-Monro（RM）算法是开山之作，著名的 SGD 是它的特例。问题是求 g(w) = 0 的根（优化问题可写成 ∇J(w) = 0，g(w) = c 可写成 g(w) − c = 0），但 g 是个黑箱：比如一个结构参数都不知道的神经网络，只能输入 w、观测带噪声的输出 g̃(w, η) = g(w) + η。RM 算法是

wk+1 = wk − ak g̃(wk, ηk)原书式 (6.5)

直观解释（原书图 6.4，g(w) = tanh(w − 1)）：wk 在根的右边时 g > 0，w 往左走；在左边时 g < 0，往右走；步子足够小就一步步靠近根。定理 6.1（RM 定理）给出几乎必然收敛的三个条件：(a) 0 < c1 ≤ ∇g(w) ≤ c2（g 单调递增，保证根存在唯一；优化时就是 J 凸；导数有上界）；(b) Σak = ∞ 且 Σak2 < ∞；(c) 噪声条件均值为 0、方差有限（不必是高斯）。

步长条件最耐人寻味。Σak2 < ∞ 要求 ak → 0：否则即使在根附近，噪声乘上不衰减的步长也会让 w 一直抖。Σak = ∞ 要求 ak 别衰减得太快：把每步位移加起来，w1 − w∞ = Σakg̃k；如果 Σak 有限，总位移就有上界 b，初值离根比 b 远就永远到不了。ak = 1/k 两条都满足：调和级数发散，Σ1/k2 = π2/6（巴塞尔问题）。实践中 ak 常取小常数，这时第二个条件不成立，但算法在某种意义下仍收敛。

应用到均值估计：令 g(w) = w − 𝔼[X]，观测 g̃ = w − x = g(w) + (𝔼[X] − x)，RM 算法正是式 (6.4)。所以 αk 满足条件时它收敛到 𝔼[X]，而且不需要对 X 的分布做任何假设。

Dvoretzky 收敛定理

原书 6.3 节 · 第 109–114 页

RM 定理的证明要借助一个更一般的经典结果。定理 6.2（Dvoretzky）：对随机过程 Δk+1 = (1 − αk)Δk + βkηk（αk, βk ≥ 0），若 (a) Σαk = ∞、Σαk2 < ∞、Σβk2 < ∞（一致几乎必然），(b) 𝔼[ηk|ℋk] = 0 且 𝔼[ηk2|ℋk] ≤ C，则 Δk 几乎必然收敛到 0。它比 RM 更有用的地方在于：αk、βk 可以是依赖历史的随机变量。

证明思路（基于拟鞅）：令 hk = Δk2，算出 𝔼[hk+1 − hk|ℋk] = −αk(2 − αk)Δk2 + βk2𝔼[ηk2|ℋk] ≤ βk2C，可求和，所以 hk 收敛；再由 ΣαkΔk2 有界而 Σαk = ∞，推出 Δk → 0。有了它，均值估计和 RM 定理的收敛都是几行的事：均值估计中令 Δ = w − 𝔼[X]，正好是 (1 − αk)Δk + αk(xk − 𝔼[X])；RM 中用中值定理把 g(wk) − g(w*) 写成 ∇g(w′)(wk − w*)，αk 变成 ak∇g(w′)，是随机的，Dvoretzky 照样适用。

定理 6.3 把它推广到多个变量（下标 s 可以是状态或状态—动作对）：Δk+1(s) = (1 − αk(s))Δk(s) + βk(s)ηk(s)，条件放宽为 ‖𝔼[ηk(s)|ℋk]‖∞ ≤ γ‖Δk‖∞（噪声均值不必为 0，只要被误差按 γ < 1 压住）和方差 ≤ C(1 + ‖Δk‖∞)2。第 7 章证明 TD 和 Q-learning 收敛用的就是它——而“噪声均值被 γ 压住”正是贝尔曼方程的收缩性。

随机梯度下降

原书 6.4 节 · 第 114–123 页

考虑 minw J(w) = 𝔼[f(w, X)]。梯度下降 wk+1 = wk − αk𝔼[∇f(wk, X)] 需要期望，而分布未知；用全部样本的平均近似它是批量梯度下降（BGD），每次要用全部样本。随机梯度下降（SGD）只用当前一个样本：

wk+1 = wk − αk∇wf(wk, xk)原书式 (6.13)

随机梯度 = 真梯度 + 零均值扰动 ηk，所以直觉上不会破坏收敛。严格地说，SGD 是 RM 算法：它在求 g(w) = 𝔼[∇f(w, X)] = 0 的根，观测是 ∇f(w, x)。定理 6.4：若 0 < c1 ≤ ∇2f ≤ c2（强凸且曲率有界）、步长满足 RM 条件、样本 i.i.d.，SGD 几乎必然收敛。再往下一层：取 f(w, X) = ‖w − X‖2/2，∇f = w − X，SGD 就是式 (6.4)——均值估计算法是 SGD 的特例。三者的包含关系：均值估计 ⊂ SGD ⊂ RM。

随机梯度这么“随机”，收敛会不会很慢？原书分析了一个有趣的规律：随机梯度相对真梯度的误差 δk ≤ |∇f(wk, xk) − 𝔼[∇f(wk, X)]| / (c|wk − w*|)，与到最优解的距离成反比。离 w* 远时相对误差小，SGD 表现得和梯度下降差不多，快速逼近；靠近 w* 后相对误差变大，才显出随机性。均值估计里 δk = |𝔼[X] − xk| / |wk − 𝔼[X]|，看得更清楚。

还有一种常见的确定性写法：min (1/n)Σf(w, xi)，每次取一个数更新。它也是 SGD——只要把 X 定义为在 {xi} 上均匀分布的随机变量，目标就严格等于 𝔼[f(w, X)]，并且应当独立、均匀地随机抽样本（可以重复）。小批量（MBGD）每次用 m 个样本平均，介于 SGD（m = 1）和 BGD 之间；注意 m = n 时 MBGD 不等于 BGD，因为随机抽的 n 个可能有重复。αk = 1/k 时三者分别给出：BGD 每步都是 x̄，MBGD 是各批均值的平均，SGD 是前 k 个样本的平均——批越大越快。

易混辨析：BGD、SGD、MBGD

BGD：每步用全部 n 个样本的平均梯度，最接近真梯度、最贵。SGD：每步随机抽 1 个样本，最便宜、最“抖”。MBGD：每步随机抽 m 个，介于两者之间；m = 1 即 SGD，m = n 也不等于 BGD（随机抽样可能重复）。

均值估计、SGD、RM 的包含关系：均值估计是 f = ‖w − X‖²/2 的 SGD；SGD 是求 𝔼[∇f] = 0 的 RM 算法。

回扣三问

  1. 怎样把平均改成增量的？换成一般 αk 还收敛吗？
    先自己答，再点开

    wk+1 = wk − (1/k)(wk − xk)，每来一个样本更新一次。换成 αk 后它是 RM 算法（g(w) = w − 𝔼[X]），只要 Σαk = ∞、Σαk2 < ∞ 且样本 i.i.d. 就几乎必然收敛，对 X 的分布没有要求。

  2. RM 凭什么能找到根？两个步长条件防止什么？
    先自己答，再点开

    g 单调递增时，w 在根右边就往左、在左边就往右，步子够小就靠近；噪声零均值，平均下来不影响方向。Σak2 < ∞ 让步长趋于 0，防止在根附近一直抖；Σak = ∞ 保证总位移无界，防止初值太远到不了根。

  3. SGD、RM、均值估计什么关系？为什么远处快、近处抖？
    先自己答，再点开

    均值估计是 f = ‖w − X‖²/2 的 SGD，SGD 是求 𝔼[∇f] = 0 的 RM 算法。随机梯度的相对误差与 |wk − w*| 成反比：远时真梯度大、噪声相对小，像梯度下降；近时真梯度小、噪声相对大，才显出随机性。
